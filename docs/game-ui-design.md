# 料理となかまが主役の育成ゲーム — UIデザイン仕様

毎日の料理が、なかまの成長と新しい出会いにつながる。画面の中心には料理となかまを置き、操作や数値はその体験を支える位置にまとめる。ひろば、食事、図鑑を通して、カヤ村で遊び続けていると感じられるデザインにする。

プレイヤーは自分の料理を記録して、ひろばの生き物を育てる。こむぎたちは人語で話さず、表情と動作で反応する。操作・状態・結果はシステムが表示する。手順説明は初回と、ユーザーが開いた「あそびかた」にまとめる。文言の責務と文字量は[UI文言ガイド](ui-writing.md)に従う。

## カヤ村の色と形

[世界設定](world.md)の「下のかまど」を美術の中心にする。海に面した土の庭、赤茶の瓦、濃い青の雨戸、低い棚に並ぶ器を、はっきりした輪郭と大きな色面で描く。海の青、麦の黄、かまどの朱を生かしたポップなゲーム画面とし、なかまと料理が背景から見分けられる構成を保つ。

UIの形は役割から決める。ひろばは一続きの場所、育成状態は場面に接する帯、料理カードは集める一枚、図鑑は手帳として見せる。器と湯気の紋をブランドに、かまど・本・市場の看板をナビゲーションに使い、世界の道具と操作をつなぐ。

太い輪郭や硬い影は、主役の絵、主操作、収集物の縁などに使う。財布、補足、タブ、二次操作まで同じ太枠の箱にしない。全カードへの色違い、同じ丸角の反復、意味のない星や英語の飾りラベルで画面を埋めない。小さな説明を増やすより、絵の大きさ、面の明暗、余白で視線を導く。

## ひろばの構成

視線は「なかまのいる場面 → 今日の状態 → ごはんをあげる → ほかの場所へ」の順に流れる。

1. **HUD**：上部には器と湯気の紋、ゲーム名、所持数を小さくまとめる。財布は静かな面と短い表示にし、長い説明や宣伝見出しを置かない。
2. **プレイフィールド**：カヤ村の下のかまどを一つの場面として見せ、中央のなかまを主役にする。海、屋根、器、庭は大きな形で描き、訪問者や料理を周囲に置く。空腹・満腹などは短い状態ラベルで示す。
3. **育成状態と主操作**：場面の下に濃い藍の帯を接続し、名前、成長ゲージ、給餌をまとめる。帯の文字は明るく、主操作はゴールドと濃紺文字。誰に何をするかが一目で分かる配置にする。
4. **下部ナビゲーション**：かまど、本、市場の絵と短いラベルで行き先を示す。選択中の面や線を変え、色だけに頼らない。画面下の安全領域を確保し、本文や主操作に重ねない。

通常・庭・夜の背景は同じカヤ村の場所として描き分ける。背景の着せ替え条件とゲーム上の効果は美術変更と独立させる。輪郭や短い影で押せる面を伝え、押下時にはわずかに沈む。すべての領域を独立したカードにせず、角丸も一律に大きくしない。

## 食事のJourney

食事は一つの画面にフォームと結果を詰め込まず、料理となかまに順に目が向く流れにする。

**写真を選ぶ・写真なしで体験する → 食卓で料理を確認する → ごはんをあげる → 食事と今回の出来事を見る → ひろばへ戻る**

- 写真選択と料理確認は短い進捗表示で位置を示す。戻る・閉じる操作を主操作から分離する。
- 各画面の見出しは目的または結果を一つ示す。主操作と同じ意味の副題や、なかまの発言に見えるキャプションを重ねない。
- 出会いの選択面にはアーチ、写真には藍の枠、食卓には縞の布を使い、場面の役割を形でも伝える。カヤ村の器やかまどにつながる表現にする。
- 写真は傾けず、大きなプレビューとして扱う。入力欄や補足は料理を囲む位置にまとめ、模様の上に本文を重ねない。
- Journeyの主操作は藍地と明るい文字、右端に黄色いアイコン面を組み合わせる。ひろばの黄色い給餌ボタンと同じ二色を使い、戻る・変更は下線や小さな輪郭で静かに見せる。
- 食事中と食後はなかまの姿を中心にする。成長、仲間入り、カード獲得、来訪、継続の贈り物は、今回発生した出来事だけを順に見せる。
- 経験値・コイン・継続日数は共通の報酬パネルにまとめる。数値ごとの大きなカードを増やして、なかまの反応より目立たせない。
- 食事演出には早送りを用意し、結果の進行や「ひろばへ」を見つけやすくする。演出を見続けることを操作完了の条件にしない。

## 図鑑の構成と情報密度

本体のコレクションは手帳の面としてまとめ、種類の切り替えは下線を使ったタブで示す。料理カードの枠と、一覧を整理する区切りを描き分ける。名前、絵、収集状態を優先し、長い説明は詳細で読む。

拡張図鑑は、大量の料理カード・なかま・アイテムを同じ世界の中で探せる画面にする。上部は「ひろばへ」「図鑑」「件数」を短く並べ、その下に種類のタブ、検索と絞り込み、一覧を置く。

- タブは「料理カード」「なかまたち」「きせかえとひろば」。アイコン、文字、件数を組み合わせ、選択状態を色だけで伝えない。
- 料理カードは、料理の絵、名前、分類、時間などの短い情報を優先する。材料・手順・長い説明は詳細で読む。カード全体を開く操作にし、同じ大きな「開く」ボタンを各カードへ繰り返さない。
- 一覧は広い画面で4列、中間幅で3列、狭い画面で2列。料理名の折り返しと画像の見分けやすさを守る。カードの説明量を増やして列幅の不足を埋めない。
- 24件ずつ表示し、検索、分類、所要時間、難易度、並び順から絞り込む。結果件数、該当なし、条件を戻す操作を一覧の近くに置く。
- 詳細は画像と説明を一つのダイアログで見せる。キーボードで閉じられ、閉じる操作と題名が分かる構造を維持する。
- 収録内容の説明は図鑑下部にまとめる。実際の解放状況と、拡張用に用意されたカタログの収録件数を混同させない。

## 文字と操作の読みやすさ

画面の見出しと主操作は各一つに絞り、説明は意味が必要なときだけ置く。ラベルには句点を付けず、本文では自然な句読点を保つ。装飾的な読点、余韻を作る文言、説明のない英語ラベルは用いない。具体例と図鑑・設定の文言の責務は[UI文言ガイド](ui-writing.md)を参照する。

明るい面では本文を濃紺、補足を濃いグレーで表示し、藍の面では明るい文字へ切り替える。文字を薄くして階層を作らず、大きさ、太さ、余白でも差を伝える。長い本文は画像や模様へ直接重ねず、無地の面を用意する。装飾書体の印象だけに頼らず、日本語の名前と本文を読みやすく保つ。

採用色同士のコントラスト比は、本文と器白の面が約11.07:1、補足と器白の面が約5.73:1、器白の文字と藍の操作色が約7.47:1、濃紺文字とゴールドが約7.26:1。これらを通常の文字と操作ラベルの基本の組み合わせとする。値は上表の単色同士からの計算であり、画像や半透明色を含む個々の画面全体の検査結果ではない。

朱と器白の面は約3.64:1のため、小さな本文の色には使わない。通知やエラーはアイコン、文言、必要に応じた濃い文字を併用する。ゴールドのボタンに白文字を載せない。

- モバイルの操作領域は44×44px以上を基準とする。小さなアイコンでも当たり領域は確保し、画面幅が狭い場合も縮めない。
- ボタン、リンク、入力欄には見えるフォーカスを残す。選択中、未選択、無効の状態を、色に加えて形・文字・操作可否で区別する。
- 検索や絞り込みには名前を付け、結果件数の変化を支援技術へ伝える。装飾アイコンを読み上げ文へ重複させない。
- なかまの動きと短い押下反応は楽しさを補助する。`prefers-reduced-motion` ではアニメーションとトランジションを止め、スクロールも即時にする。動きがなくても進行と結果が分かる構造を保つ。

## 実装の対応

| 実装                                         | 受け持つ範囲                                                                        |
| -------------------------------------------- | ----------------------------------------------------------------------------------- |
| `public/game-tokens.css`                     | 本体と図鑑で共有する色、基本の角丸、影。採用パレットの定義元。                      |
| `src/KayaScenery.tsx`                        | カヤ村の下のかまどを描く独自SVG。通常・庭・夜の背景。                               |
| `src/GameMotifs.tsx`                         | 器と湯気の `MoguMark`、かまど・本・市場の `VillageSign`。                           |
| `src/GameArt.tsx`                            | なかまや料理などの描画APIと、ひろば背景への接続。                                   |
| `src/game-theme.css`                         | 本体のHUD、ひろば、主操作、下部ナビゲーション、コレクション、ショップ、ダイアログ。 |
| `src/journey-theme.css`                      | 出会い・写真選択・料理確認・食事・成果表示のJourneyの配色と面。                     |
| `public/expansion/index.html`                | 拡張図鑑のヘッダー、タブ、検索、一覧、詳細の構造。共有トークンを読み込む。          |
| `public/expansion/catalog.css`・`catalog.js` | 拡張図鑑の配置、カード表示、検索、絞り込み、ページ切替、詳細表示。                  |

本体も `index.html` から共有トークンを読み込む。色は共有トークン、操作面は本体とJourneyそれぞれのテーマで管理する。既存の機能ごとの配置CSSは保ち、別のテーマファイルを追加して上書きを積み重ねない。背景と紋は本作のために描いたSVGを使い、参照作品の素材を組み込まない。

新しいレシピ、なかま、アイテムを追加するときも、一覧の密度や操作色を種類ごとに増やさない。内容の多様さは絵と設定で見せ、遊び方の手掛かりは同じ位置、同じ言葉、同じ色で保つ。

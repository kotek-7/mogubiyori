# 初回のコンセプト紹介

初回は「アプリの紹介3画面 → 最初のなかまを選ぶ → チュートリアル」の順に進む。操作の練習より先に、自炊が成長・出会い・収集の楽しみにつながることを伝える。

| 画面 | 見出し                       | 伝えること                                                     |
| ---- | ---------------------------- | -------------------------------------------------------------- |
| 1    | きみのごはんで、なかまが育つ | 自分で作った料理を記録して、小さな生き物「もぐ」を育てるゲーム |
| 2    | 今日の一皿を、おすそわけ     | 料理の写真からごはんをあげると、なかまが少しずつ成長する       |
| 3    | 次のごはんが、楽しみになる   | 育つ姿・新しいなかま・料理カードが、次の自炊の楽しみになる     |

各画面はイラスト・見出し・説明1文で構成し、「つづける」で読み進め、最後の「なかまを選ぶ」で選択画面へ進む。自動では進めず、2画面目以降は前の紹介へ戻れる。「紹介をスキップ」から直接なかま選択へ進むこともできる。設定は紹介中も開けるので、既存アカウントへの接続を妨げない。育った姿はここでは公開せず、もぐのセリフや案内人物も追加しない。

完了・スキップでは既存の保存経路で `tutorial.introSeen: true` を保存してから進む。なかま選択前に再起動しても既読を保持する。紹介途中の再起動では最初から表示し、なかまがいる既存セーブではフィールドがなくても紹介を挟まない。初期状態へのリセット後は再び表示する。紹介では経験値・コイン・食事・チュートリアルの章や完了状態を変更しない。

参考は [Pokémon Sleep公式紹介](https://www.pokemonsleep.net/pokemon/) の「生活習慣がゲーム内の発見につながる」という伝え方と、日常の流れから次の出会いへ進む構成。公式紹介ページを参照したもので、実アプリの初回起動画面を再現するものではない。

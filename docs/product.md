# もぐ日和

きみのごはんで、なかまが育つ。

## 届けたい体験

丁寧な生活に憧れながら、授業やアルバイトで自炊が続かない下宿大学生に向けた育成ゲーム。自分のためだけでは後回しになる料理を、小さななかまと分けあう時間にする。

目標は、自炊を続けられること。「次はどんな姿になるだろう」「あの子にも食べさせたい」「料理カードを集めたい」が、次の一皿を作る理由になるかを確かめる。

## 遊びの流れ

初回は最初のなかまを選び、5画面のチュートリアルへ進む。ごはんをあげる、育った姿を見る、お客さんをなかまにする、料理カードを獲得する、という操作と結果を体験し、最後は3日間の連続記録と報酬の変化を自動再生で見る。練習中のXP・加入・カード・コイン・日付は本編に反映しない。

完了後は「はじめてのごはんへ」から自分の料理を記録する。「あとで記録する」でひろばへ進むこともできる。途中で中断した場合は画面単位で進み具合を保存し、ひろばや設定から再開できる。チュートリアル導入前からなかまのいるセーブでは自動表示せず、設定から任意で体験できる。画面ごとの操作と保存仕様は[チュートリアル設計](tutorial.md)を参照。

1. 写真の画面で料理を撮る・選ぶ。写真なしの体験は直接食卓へ進める。
2. 食卓で相手と料理を確かめ、ごはんをあげる。料理の選択と名前は任意。写真に戻っても入力は保つ。
3. なかまが食べる。食後は獲得XP、累計XPの増加、成長ゲージの伸びを表示する。XP獲得と連続記録の更新の画面は、ボタンを押すまで表示し続ける。
4. 成長・新加入・初めてのカード・来客・7日の贈り物があれば、それぞれ独立した場面で一つずつ祝う。
5. お客さんにも料理を分け、なかまと料理カードを集めながら暮らす。

ごはんの途中は通貨やタブを隠し、次の操作に集中できるようにする。記録と報酬は「ごはんをあげる」で一度だけ確定する。食事演出の早送りや「つづける」で追加報酬は発生しない。給餌前の中止では記録を残さない。

主要なタブは「ひろば・ずかん・おみせ」。ひろばはなかまとの暮らし、ずかんはなかまと料理の収集、おみせはきせかえを担う。料理を決めたいときは、ずかんで全310種の材料・時間・手順を確認できる。ずかんと食卓では同じ検索一覧を使い、名前・材料・タグの検索と、種類・調理時間・難しさ・獲得状態の絞り込みに対応する。1ページ24品を表示し、未獲得でもレシピ全文を読んで料理を選べる。

## なかまと成長

なかまは、こむぎ・まめ・しずく・ゆず・もも・ごまの6種類。最初はこむぎ・まめ・しずくから1匹選ぶ。経験値は個体ごとに持ち、おせわする相手を切り替えられる。

| 経験値       | 姿         | 通常のごはんでの最短到達 |
| ------------ | ---------- | ------------------------ |
| 0〜119 XP    | うまれたて | 出会ったとき             |
| 120〜299 XP  | ちびっこ   | 3食目                    |
| 300〜599 XP  | わんぱく   | 7食目                    |
| 600〜1049 XP | おとな     | 14食目                   |
| 1050 XP以上  | とっておき | 24食目                   |

本編の初回のごはんの後は45 XPで、うまれたての姿を保つ。2食目でも90 XPまでで、初期の姿と暮らしてから最初の変化を迎える。初回の報酬は獲得XPと料理カードで伝える。チュートリアルでは育った姿を例示するが、本編の成長を早めることはない。

成長は縮尺の変更だけで表現せず、体形、手足、耳・翼・尾などの輪郭を段階ごとに変える。未発見のなかまと成長段階はずかんにシルエットで並べ、名前は「？？？」とする。出会った姿は色付きになり、プロフィールでいつでも見返せる。通常の報酬では1食で複数段階を飛び越えない。将来一度に大きなXPが入る場合も、成長演出は各段階を順に見せる。

ごはんは通常45 XP。同じ相手に同じ登録料理が連続すると、2回目30 XP、3回目以降15 XPになる。別の料理を挟むと45 XPに戻る。1日に複数回ごはんをあげられ、そのたびに育つ。料理未選択の記録は45 XP。

毎食、3.6秒の食事演出の直後に獲得XPを大きく表示し、食べたなかまの累計XPと成長ゲージを増やす。食事演出は「早送り」で先へ進める。XP獲得と連続記録の更新の結果は自動では閉じず、「つづける」または「ひろばへ」を押すまで表示する。成長する食事では、直前の段階のゲージが満ちてから姿の変化を見せる。段階をまたいでもゲージが減って見えないようにし、余剰XPも累計へ含める。最終形でも獲得XPと累計は表示する。動きを減らす設定では数値を即時に確定表示する。

わんぱく以上のなかまがいると、まだ迎えていない種類から最大3匹のお客さんが現れる。ごはんをあげると正式ななかまになり、その子のおせわに切り替わる。

## 料理カードとコイン

レシピは既存10種と追加300種の計310種。難しさ・調理時間・材料・手順を持ち、追加分は分量・コツ・道具も表示する。本人が選んだ登録料理を初めて記録すると、料理カードを獲得する。レア度は料理ごとに固定し、抽選ではない。カードの初回報酬はノーマル20・レア40・スペシャル70コイン。既存のカードIDと食事履歴を維持し、追加料理も保存・再読み込み後に同じカードとして扱う。

未獲得のカードは一覧・詳細ともに料理のシルエットを表示し、獲得すると色付きの絵に変わる。料理名・材料・手順は未獲得でも読める。チュートリアルの未獲得カードと未発見の成長段階も同じ見せ方にする。

| 条件                 | コイン       |
| -------------------- | ------------ |
| その日最初のログイン | 20           |
| その日最初の自炊記録 | 30           |
| 初めての料理カード   | 20 / 40 / 70 |
| 3日継続              | 30           |
| 7日ごとの継続        | 100          |

条件が重なれば合算する。同じ日の追加記録でも新しい料理カードの報酬は受け取れるが、その日の自炊報酬は増えない。7日継続時は「ふたばのかんむり」も獲得し、食後に身につけてひろばへ戻る。

## 空腹と連続記録

日付は日本時間単位。今日ごはんを食べた子の満腹度は96、最後が昨日なら28、それ以前なら8。作れない日があっても死亡や経験値の減少はなく、今日の一皿から戻れる。

連続記録は自分が料理を記録した日数で、なかまごとには分けない。今日が未記録なら昨日までの継続を表示する。記録も保護もない日を越えると途切れる。

おやすみチケットは最初に2枚。未記録の日に連続記録画面の「今日はおやすみ」から使う。1枚でその日の連続記録を保護し、継続日数は増やさない。なかまのおなかも満たさない。同じ日に料理を記録したらチケットを返す。ごはんのお知らせは「ひかえめ」「しっかり」から選べる。

## 写真と記録

写真を選ぶと、Cloudflare Workers AIのGemma 4で料理を認識し、全310種のレシピから最大3件を候補として提示する。最初の候補を食卓の料理選択へ反映し、プレイヤーは候補や「料理を選ぶ」の検索一覧から変更できる。料理カードから選んで来た場合や、すでに手動で選んだ場合は、その選択を優先する。写真を替えたり体験を中止した場合、古い写真の判定結果は使わない。

判定は写真の読込後に始まり、結果を待たずに食卓へ進める。該当料理がない場合や通信失敗時も手動で記録できる。判定結果だけではカード・XP・通貨を付与せず、「ごはんをあげる」で選択中のレシピを確定する。

料理名が未入力なら、選択中のレシピ名、選択もなければ「今日のごはん」として保存する。自由入力の料理名は判定結果で上書きしない。栄養や料理の出来栄えは採点しない。写真なしの体験では料理イラストを使い、モデルを呼び出さない。追加料理の固有イラストは、レシピ詳細・獲得済みカード・食卓・カード獲得・写真のない食事履歴で共通に使う。

成長ルールは `growthVersion: 2`。旧セーブの経験値は区間内の進捗を保ちながら、旧ちびっこ→うまれたて、旧すくすく→わんぱく、旧おとな→おとなへ一度だけ移行する。食事履歴・通貨・加入済みのなかまは維持する。

保存はブラウザ内。記録後の編集・削除、過去日への記録、端末間同期は未対応。写真から料理の候補を提案するが、自炊したかどうかは自己申告とする。写真は端末で縮小し、料理判定のためCloudflareへ送る。

## きせかえと事業の仮説

コインやジェムで帽子・首元・かばん・ひろばの背景を手に入れる。帽子、首元、かばん、背景はそれぞれ独立した装備枠を持ち、同時に使用できる。購入時に通貨を引き、購入品の部位だけを切り替える。所有済みのアイテムは再購入せず切り替えられ、帽子・首元・かばんはそれぞれ無料で外せる。試着はほかの部位を維持し、食卓・食事・成長後にも組み合わせを引き継ぐ。衣装による経験値・報酬の差はない。

拡張パックから帽子6点を採用し、首元4点とかばん4点を追加した。首元はバンダナ・リボン・マフラー・貝がらペンダント、かばんはポシェット・ピクニックかご・どんぐりポーチ・星くずバッグ。旧セーブの所持品・残高・成長は維持し、追加された部位は装備なしで始める。

ジェムは有料通貨の体験用で、試用操作1回で150個追加できる。実際の請求はない。事業の仮説は、なかまへの愛着と収集の楽しさが衣装・背景の購入につながること。価格・販売頻度・季節イベントは検証対象とする。

空腹を解消する課金は自炊の理由を弱める可能性がある。育成の近道や限定品を検討するときも、自炊したくなる気持ちとの両立を確かめる。

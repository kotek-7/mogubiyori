# もぐ日和

きみのごはんで、なかまが育つ。

## 届けたい体験

丁寧な生活に憧れながら、授業やアルバイトで自炊が続かない下宿大学生に向けた育成ゲーム。自分のためだけでは後回しになる料理を、小さななかまと分けあう時間にする。

目標は、自炊を続けられること。「次はどんな姿になるだろう」「あの子にも食べさせたい」「料理カードを集めたい」が、次の一皿を作る理由になるかを確かめる。

## 遊びの流れ

1. 最初のなかまを選び、ひろばへ迎える。
2. 作った料理の写真を届ける。料理の選択と料理名は任意。
3. ごはんで経験値が増え、なかまの姿が変わる。
4. おとなまで育つと、新しいお客さんが遊びにくる。
5. お客さんにも料理を分け、新しいなかまとして迎える。
6. 料理カードや着せ替えを集めながら、毎日の自炊を続ける。

主要なタブは「ひろば・ずかん・おみせ」。ひろばはキャラクターとの暮らし、ずかんはなかまと料理の収集、おみせは着せ替えを担う。料理を決めたいときは、ずかんで材料・時間・手順を確認できる。

## なかまと成長

なかまは、こむぎ・まめ・しずく・ゆず・もも・ごまの6種類。最初はこむぎ・まめ・しずくから1匹選ぶ。経験値は個体ごとに持ち、おせわする相手を切り替えられる。

| 経験値     | 姿       |
| ---------- | -------- |
| 0〜44 XP   | ちびっこ |
| 45〜119 XP | すくすく |
| 120 XP以上 | おとな   |

ごはんは通常45 XP。同じ相手に同じ登録料理が連続すると、2回目30 XP、3回目以降15 XPになる。別の料理を挟むと45 XPに戻る。1日に複数回ごはんをあげられ、そのたびに育つ。料理未選択の記録は45 XP。

おとなのなかまがいると、まだ迎えていない種類から最大3匹のお客さんが現れる。ごはんをあげると正式ななかまになり、その子のおせわに切り替わる。

## 料理カードとコイン

レシピは難しさ・調理時間・材料・手順を持つ。本人が選んだ登録料理を初めて記録すると、料理カードを獲得する。レア度は料理ごとに固定し、抽選ではない。カードの初回報酬は難しさに応じて20・40・70コイン。

| 条件                 | コイン       |
| -------------------- | ------------ |
| その日最初のログイン | 20           |
| その日最初の自炊記録 | 30           |
| 初めての料理カード   | 20 / 40 / 70 |
| 3日継続              | 30           |
| 7日ごとの継続        | 100          |

条件が重なれば合算する。同じ日の追加記録でも新しい料理カードの報酬は受け取れるが、その日の自炊報酬は増えない。7日継続時は「ふたばのかんむり」も獲得し、食後に身につけてひろばへ戻る。

## 空腹と継続

日付は日本時間単位。今日ごはんを食べた子の満腹度は96、最後が昨日なら28、それ以前なら8。作れない日があっても死亡や経験値の減少はなく、今日の一皿から戻れる。

ストリークは自分が料理を記録した日数で、なかまごとには分けない。今日が未記録なら昨日までの継続を表示する。記録も保護もない日を越えると途切れる。

おやすみチケットは最初に2枚。未記録の日にストリーク画面の「今日はおやすみ」から使う。1枚でその日のストリークを保護し、継続日数は増やさない。なかまのおなかも満たさない。同じ日に料理を記録したらチケットを返す。催促の口調は「ひかえめ」「ぐいぐい」から選べる。

## 写真と記録

料理名が未入力なら、明示的に選んだレシピ名、選択もなければ「今日のごはん」として保存する。写真から料理名を推測して埋めない。栄養や料理の出来栄えは採点しない。写真なしの体験では料理イラストを使う。

保存はブラウザ内。記録後の編集・削除、過去日への記録、端末間同期は未対応。自炊の判定は自己申告であり、画像認識は接続していない。

## 着せ替えと事業の仮説

コインやジェムで帽子・ひろばの背景を手に入れる。購入時に通貨を引き、購入品を装着する。所有済みのアイテムは再購入せず切り替えられる。

ジェムは有料通貨の体験用で、試用操作1回で150個追加できる。実際の請求はない。事業の仮説は、なかまへの愛着と収集の楽しさが衣装・背景の購入につながること。価格・販売頻度・季節イベントは検証対象とする。

空腹を解消する課金は自炊の理由を弱める可能性がある。育成の近道や限定品を検討するときも、自炊したくなる気持ちとの両立を確かめる。

# もぐ日和

きみのごはんで、なかまが育つ。

## 届けたい体験

丁寧な生活に憧れながら、授業やアルバイトで自炊が続かない下宿大学生に向けた育成ゲーム。自分のためだけでは後回しになる料理を、小さななかまと分けあう時間にする。

目標は、自炊を続けられること。「次はどんな姿になるだろう」「あの子にも食べさせたい」「料理カードを集めたい」が、次の一皿を作る理由になるかを確かめる。

## 遊びの流れ

初回は最初のなかまを選び、5画面のチュートリアルへ進む。最初は大きな「今日の料理を一枚」から直接撮影して、ごはんをあげる。撮影済みの写真や、写真付きのサンプルボタンからも直接進める。成長・なかまの加入・料理カード・連続記録は自動デモで仕組みを知る。デモ中も次の章へ進め、サンプル写真なら7タップでひろばに着く。説明は各章を通じて表示し、2〜4章のデモは一時停止や再生もできる。練習中のXP・加入・カード・コイン・日付は本編に反映しない。

最後の章の「ひろばへ」で通常画面へ進む。途中でひろばへ移る「スキップ」はヘッダー右上に置き、章を進める画面下部のボタンと分ける。ひろばでは実際の「ごはんをあげる」から自分の料理を記録する案内を表示する。途中で中断した場合は画面単位で進み具合を保存し、ひろばや設定から再開できる。チュートリアル導入前からなかまのいるセーブでは自動表示せず、設定から任意で体験できる。画面ごとの操作と保存仕様は[チュートリアル設計](tutorial.md)を参照。

1. 写真の画面で料理を撮る・選ぶ。サンプル写真での体験は、ランダムに選んだ写真を撮影UIで大きく見せ、シャッターの演出から同じ写真が食卓のお皿へ移る。文字を重ねず、背景は一瞬だけ薄い半透明の黒にし、約0.8秒の演出で料理を撮ってごはんをあげる流れを伝える。動きを減らす設定では背景の変化・フラッシュ・移動のアニメーションを省く。
2. 食卓で相手と自分で作った料理を確かめ、ごはんをあげる。記録は自炊として扱い、「食事の内容を確認」には写真から読み取った料理・量・食品群が入る。必要に応じて修正し、食事の時間や写っていない料理も補える。料理の選択と名前は任意。写真に戻っても入力は保つ。
3. なかまが食べる。食後は獲得XP、累計XPの増加、成長ゲージの伸びを表示する。XP獲得と連続記録の更新の画面は、ボタンを押すまで表示し続ける。
4. 成長・新加入・初めてのカード・来客・7日の贈り物があれば、それぞれ独立した場面で一つずつ祝う。
5. 「今日のごはんを振り返ろう」で、今日のスコアと食品群を確認する。ひろばへ戻るか、その日の記録・7日間のレポートへ進む。
6. 記録した今日の食事をほかのなかまやお客さんへおすそわけできる。人が食べた記録は1件として数える。

ごはんの途中は通貨やタブを隠し、次の操作に集中できるようにする。記録と報酬は「ごはんをあげる」で一度だけ確定する。食事演出の早送りや「つづける」で追加報酬は発生しない。給餌前の中止では記録を残さない。

主要なタブは「ひろば・記録・レポート・ずかん・おみせ」。ひろばはなかまとの暮らし、記録は作った料理の履歴と追加、レポートは自炊の継続と食事の振り返り、ずかんはなかまと料理の収集、おみせはきせかえを担う。ひろばにも今日の自炊食数と判定できたスコアを表示し、レポートへ直接進める。

料理を決めたいときは、ずかんで無料プランは定番30種、有料プランは全310種の材料・時間・手順を確認できる。ずかんと食卓では同じ検索一覧を使い、名前・材料・タグの検索と、種類・調理時間・難しさ・獲得状態の絞り込みに対応する。1ページ24品を表示し、未獲得でもレシピ全文を読んで料理を選べる。

## なかまと成長

なかまは、こむぎ・まめ・しずく・ゆず・もも・ごまの6種類。最初はこむぎ・まめ・しずくから1匹選ぶ。経験値は個体ごとに持ち、おせわする相手を切り替えられる。

ずかんの「なかま」では、カードの「説明を見る」から生態・性格・出会った成長段階の説明を開く。姿を選ぶと、体の説明と「しぐさ」がその段階の内容に切り替わる。お客さんの説明も読める。閲覧ではおせわする相手や育成記録を変えず、閉じると一覧に戻る。相手の切り替えは別の「ひろばに呼ぶ」で行う。未発見のなかまの説明はまだ開けない。

| 経験値       | 姿         | 通常のごはんでの最短到達 |
| ------------ | ---------- | ------------------------ |
| 0〜119 XP    | うまれたて | 出会ったとき             |
| 120〜299 XP  | ちびっこ   | 3食目                    |
| 300〜599 XP  | わんぱく   | 7食目                    |
| 600〜1049 XP | おとな     | 14食目                   |
| 1050 XP以上  | とっておき | 24食目                   |

本編の初回のごはんの後は45 XPで、うまれたての姿を保つ。2食目でも90 XPまでで、初期の姿と暮らしてから最初の変化を迎える。初回の報酬は獲得XPと料理カードで伝える。チュートリアルでは育った姿を例示するが、本編の成長を早めることはない。

成長は縮尺の変更だけで表現せず、体形、手足、耳・翼・尾などの輪郭を段階ごとに変える。未発見のなかまと成長段階はずかんにシルエットで並べ、名前は「？？？」とする。出会った姿は色付きになり、プロフィールでいつでも見返せる。通常の報酬では1食で複数段階を飛び越えない。将来一度に大きなXPが入る場合も、成長演出は各段階を順に見せる。

ごはんは通常45 XP。同じ相手に同じ登録料理が連続すると、2回目30 XP、3回目以降15 XPになる。別の料理を挟むと45 XPに戻る。1日に複数回ごはんをあげられ、そのたびに育つ。料理未選択の記録は45 XP。

毎食、3.6秒の食事演出の直後に獲得XPを大きく表示し、食べたなかまの累計XPと成長ゲージを増やす。食事演出は「早送り」で先へ進める。XP獲得と連続記録の更新の結果は自動では閉じず、「つづける」または「ひろばへ」を押すまで表示する。成長する食事では、直前の段階のゲージが満ちてから姿の変化を見せる。段階をまたいでもゲージが減って見えないようにし、余剰XPも累計へ含める。最終形でも獲得XPと累計は表示する。動きを減らす設定では数値を即時に確定表示する。

わんぱく以上のなかまがいると、まだ迎えていない種類から最大3匹のお客さんが現れる。ごはんをあげると正式ななかまになり、その子のおせわに切り替わる。

## 料理カードとコイン

レシピは既存10種と追加300種の計310種。難しさ・調理時間・材料・手順を持ち、追加分は分量・コツ・道具も表示する。本人が選んだ登録料理を初めて記録すると、料理カードを獲得する。レア度は料理ごとに固定し、抽選ではない。カードの初回報酬はノーマル20・レア40・スペシャル70コイン。既存のカードIDと食事履歴を維持し、追加料理も保存・再読み込み後に同じカードとして扱う。

未獲得のカードは一覧・詳細ともに料理のシルエットを表示し、獲得すると色付きの絵に変わる。各プランで利用できるレシピは、料理名・材料・手順を未獲得でも読める。チュートリアルの未獲得カードと未発見の成長段階も同じ見せ方にする。

| 条件                 | コイン       |
| -------------------- | ------------ |
| その日最初のログイン | 20           |
| その日最初の自炊記録 | 30           |
| 初めての料理カード   | 20 / 40 / 70 |
| 3日継続              | 30           |
| 7日ごとの継続        | 100          |

条件が重なれば合算する。同じ日の追加記録でも新しい料理カードの報酬は受け取れるが、その日の自炊報酬は増えない。7日継続時は「ふたばのかんむり」も獲得し、食後に身につけてひろばへ戻る。

## 空腹と連続記録

日付は日本時間単位。今日ごはんを食べた子の満腹度は96、最後が昨日なら28、それ以前なら8。作れない日があっても死亡や経験値の減少はなく、今日の一皿から戻れる。

連続記録は自分が料理を記録した日数で、なかまごとには分けない。今日が未記録なら昨日までの継続を表示する。記録も保護もない日を越えると途切れる。

おやすみチケットは最初に2枚。ごはんの連続記録が3日増えるごと（3・6・9日目…）に1枚を自動で受け取る。同じ日の追加記録では増えず、おやすみの日は獲得までの日数に数えない。連続記録画面では所持枚数と次の1枚までの日数を確認でき、獲得時は食後にお知らせする。未記録の日に連続記録画面の「おやすみチケットを使う」から使う。1枚でその日の連続記録を保護し、継続日数は増やさない。なかまのおなかも満たさない。同じ日に料理を記録したらチケットを返し、3日ごとの獲得条件も満たせば報酬の1枚も受け取る。ごはんのお知らせは「ひかえめ」「しっかり」から選べる。

## 写真と記録

写真を選ぶと、Cloudflare Workers AIのGemma 4で料理を認識し、全310種のレシピと201種の料理から主な料理の候補を最大3件提示する。具材や味付けが分からない場合も、見分けられる料理名で記録できる。主な料理を食卓の料理選択へ反映し、プレイヤーは候補や「料理を選ぶ」の検索一覧から変更できる。料理カードから選んで来た場合や、すでに手動で選んだ場合は、その選択を優先する。

「料理の種類で選ぶ」は主食・主菜・副菜・汁物・おやつなどを10分類で整理する。名前・読み・別名の検索と種類による絞り込みを組み合わせ、12件ずつ表示する。選択中の料理がある場合は、その料理を含むページから開く。ひらがな・カタカナ・半角カナを同じ読みとして探せる。種類での記録は通常の経験値と毎日の報酬の対象となり、具体的なレシピを選んだときだけ料理カードを獲得する。

主菜・ごはん・副菜など、写真に写る最大12品の名前・食品群・量を「食事の内容を確認」へ自動入力する。カタログにない料理も名前を付けて記録できる。量は少なめ・ふつう・多めの目安で、判断できない場合は未設定にする。食事の時間や用意のしかたは写真から推測せず、時間の初期値は未設定のまま、自炊の扱いも維持する。追加の確認操作は増やさず、入力された内容を「ごはんをあげる」で保存する。写真を差し替えたときは古い写真の自動入力と副菜を取り除き、手修正は保つ。体験を中止したときは下書きを破棄し、古い判定結果を後から反映しない。

判定は写真の読込後に始まり、結果を待たずに食卓へ進める。該当料理がない場合や通信失敗時も手動で記録できる。判定結果だけではカード・XP・通貨を付与せず、「ごはんをあげる」で選択中のレシピを確定する。

料理名が未入力なら、食事内容の先頭の料理名、選択もなければ「今日のごはん」として保存する。自由入力の料理名や手修正した食品群・量・副菜は遅い判定結果で上書きしない。サンプル写真での体験はランダムに選んだ写真を食卓と保存履歴に使い、モデルを呼び出さない。追加料理の固有イラストは、レシピ詳細・獲得済みカード・食卓・カード獲得・写真のない食事履歴で共通に使う。

成長ルールは `growthVersion: 2`。旧セーブの経験値は区間内の進捗を保ちながら、旧ちびっこ→うまれたて、旧すくすく→わんぱく、旧おとな→おとなへ一度だけ移行する。食事履歴・通貨・加入済みのなかまは維持する。

保存はlocalモードではブラウザ内、cloudモードではユーザーごとにSupabaseへ行う。食事の内容と日付は記録後に編集でき、レポートを再計算する。育成のXP・コイン・カード・連続記録は変更しない。記録の削除と過去日への新規入力は未対応。以前の給餌履歴はそのまま閲覧でき、食品群がない記録を推測で採点しない。写真から料理・食品群・量を提案するが、自炊したかどうかは自己申告とする。写真は端末で縮小し、料理判定のためCloudflareへ送る。

## 食事の振り返り

食後には今日の食事スコア、記録・判定・自炊の食数、主食、肉・魚・卵・豆、野菜・きのこ・海藻、果物、乳製品の記録を1画面で表示する。「ごはんの記録を見る」と「7日間のレポートを見る」からそれぞれの画面へ進める。通常画面では下のメニューからいつでも開ける。

記録画面では日付と写真の履歴を先に見せ、今日の自炊を記録するボタンを常設する。レポート画面には7日間のグラフ、食品群の推移、選んだ日のバランスを表示する。両画面のリンクは日付と期間を保ち、再読み込みやブラウザの戻る・進むでも復元する。記録・レポートから食事入力を開いて中止した場合も、元の画面と日付へ戻る。

スコアは主食30点・肉魚卵豆30点・野菜40点の組み合わせを、判定できた食事で平均する。間食はスコアに含めず、食品群には含める。量を測らず、カロリーや栄養素の充足度を表さない。果物と乳製品は別に振り返る。分類が不明な食事や未記録の日は点数を付けず、記録できた範囲を明示する。細かい計算・保存ルールは[食事レポートの仕様](meal-reports.md)を参照する。

## サブスクリプションときせかえ

食事記録やログインで貯まるコインで、帽子・首元・かばん・ひろばの背景を手に入れる。帽子、首元、かばん、背景はそれぞれ独立した装備枠を持ち、同時に使用できる。購入時にコインを引き、購入品の部位だけを切り替える。暫定的にコイン不足でも購入でき、不足時の残高は0にする。所有済みのアイテムは再購入せず切り替えられ、帽子・首元・かばんはそれぞれ無料で外せる。試着はほかの部位を維持し、食卓・食事・成長後にも組み合わせを引き継ぐ。衣装による経験値・報酬の差はない。

拡張パックから帽子6点を採用し、首元4点とかばん4点を追加した。首元はバンダナ・リボン・マフラー・貝がらペンダント、かばんはポシェット・ピクニックかご・どんぐりポーチ・星くずバッグ。旧セーブの所持品・残高・成長は維持し、追加された部位は装備なしで始める。

収益モデルはサブスクリプション「もぐ日和プラス」。無料は今日を含む直近3日分の栄養レポート、1日1回の新しいごはん記録、定番30品のレシピ、広告あり。有料は全期間の栄養レポート、1日複数回の記録、全310品のレシピ、広告なしとする。料金は未設定。

右上の「プラスに加入」または設定の「会員プラン」で、無料・有料を自由に切り替えられる。有料会員の右上は「プラス会員」と表示し、現在のプランを確認できる。請求はモックで料金は発生せず、プランはlocal/cloudそれぞれの保存先へ記録する。既存セーブは無料プランとして読み込む。無料へ戻しても食事・カードは削除せず、有料へ戻すと再び閲覧できる。食事そのものの履歴閲覧は全期間を維持し、3日制限はレポートに適用する。同じ食事のおすそわけは追加記録として数えず、無料でも利用できる。

無料の記録・レポート・ずかん・おみせには「広告・サンプル」と明記した料理カードの案内を表示する。ひろばは全画面のまま保ち、広告を重ねない。広告配信サービスへの接続は行わない。ジェム販売・追加による都度課金は廃止し、きせかえの価格は数値を維持してコインへ統一する。既存ジェムは保存データの読み込み時に1個につき1コインへ一度だけ移し、所持品や育成状況は維持する。

空腹を解消する課金は自炊の理由を弱める可能性がある。育成の近道や限定品を検討するときも、自炊したくなる気持ちとの両立を確かめる。

## 成長設計の参照

# もぐ日和

きみのごはんで、こむぎが育つ。

## 届けたい体験

丁寧な生活に憧れながら、授業やアルバイトで自炊が続かない下宿大学生に向けた育成ゲーム。自分のためだけでは後回しになる料理を、小さな相棒「こむぎ」のごはんにする。

目的は料理の完成度を上げることより、自炊を続けられること。簡単な一品、同じ料理、レンジ調理も同じように育成につながる。「会いたい」「食べさせたい」が、今日作る理由になるかを確かめる。

## 一日の流れ

1. おへやを開く。こむぎの表情で、おなかの状態がわかる。
2. 料理の写真を選ぶ。料理名は必要なときだけ添える。
3. ごはんをあげる。こむぎが食べ、経験値・コイン・ストリークが増える。
4. 食後のおへやへ戻る。明日も会いたくなる余韻で終える。

各段階の主な操作は1つ。ホームの中心はこむぎと、ごはんをあげるボタン。着せ替えや過去の写真は記録の途中に挟まない。

| 場所   | 役割                                     |
| ------ | ---------------------------------------- |
| おへや | こむぎの状態を見て、ごはんをあげる       |
| 思い出 | 自分で作った料理を振り返る               |
| おみせ | 帽子やおへやを選び、購入・着せ替えする   |
| 設定   | 日付のシミュレーション、口調変更、初期化 |

## 育成と継続のルール

| 条件                     | 結果                               |
| ------------------------ | ---------------------------------- |
| その日最初のごはん       | 45 XP、30コイン、ストリークを更新  |
| 同じ日の追加のごはん     | 思い出に保存。追加のXP・コインなし |
| 今日ごはんをあげた       | おなか96                           |
| 最後のごはんが昨日       | おなか28                           |
| 最後のごはんが一昨日以前 | おなか8                            |
| 7日継続を達成            | ふたばのかんむりを獲得             |

レベルは100 XPごとに1つ上がる。初期体験はLv.3・6日継続から始まり、今日のごはんでLv.4と7日継続に到達する。初めての状態ではLv.1・おなか8から始まり、初めてのごはんを待つ。報酬で得たかんむりは、食後に身につけておへやへ戻る。おみせからいつでも着せ替えられる。

日付は日本時間単位。今日が未記録なら昨日までのストリークを表示し、記録も保護もない日を越えると途切れる。空腹でキャラクターが死亡したり、経験値が減ったりすることはない。作れなかった後も、今日の一皿で戻れる。

おやすみチケットは最初に2枚。未記録の日に1枚使うと、その日のストリークを保護する。継続日数は増えず、空腹も解消しない。その日に料理を記録したらチケットを返す。

## ごはんの記録

写真1枚で記録できる。写真から料理名や自炊の有無を推測して埋めない。料理名が未入力なら「今日のごはん」として扱う。画像の内容によって経験値を変えず、料理の難しさや栄養を採点しない。

写真はブラウザ内で縮小して保存する。サンプルの一皿は写真なしで操作を試すための入口。保存後の編集・削除、過去日への記録、端末間同期は今後の検討対象。

## 着せ替えと課金の仮説

帽子はどんぐりベレー、ふたばのかんむり、コックさんの帽子。おへやはいつものおへや、木もれびのおへや、星あかりのおへやを用意する。購入時に所持通貨を引き、購入したものを身につける。所有済みのアイテムは再購入せず切り替えられる。

コインは自炊で獲得する通貨、ジェムは有料通貨の体験用。ジェムは1回の試用操作で150個追加でき、実際の請求はない。

事業の仮説は「こむぎへの愛着が、見た目を変えるアイテムへの支払いにつながること」。衣装や部屋の追加を軸に、価格・販売頻度・季節イベントを検討する。空腹を解消する課金を採用すると、自炊する理由を弱める可能性があるため、継続への影響を別途確かめる。

## 次に決めること

- 空腹の表情と催促は、料理を始めるきっかけになるか、アプリを閉じる理由になるか。
- 自炊の範囲をどう伝えるか。簡単な調理を認めながら、写真提出だけが目的にならないか。
- 成長の見た目や行動を、何日ごとに増やすと会いたくなるか。
- おやすみの保護と空腹の関係が、忙しい生活に無理なく馴染むか。
- 衣装への支払い意思と、学生が続けられる価格はどこで両立するか。

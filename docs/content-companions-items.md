# なかまときせかえの拡張パック

36 種の新しいなかま、各 5 段階の成長イラスト、36 点の帽子、36 場面の背景を収録する。既存のなかま・アイテム・保存データには変更を加えない。全イラストは、このパック用に作成した SVG の独立したファイルで、外部画像・Web フォント・画像生成サービスには依存しない。

## アートの方針

町の食堂の印刷物と、食材の観察図鑑をイメージした平面的な絵柄。濃い墨色の輪郭、朱色、青、深緑、黄色を基調に、形と面で特徴を示す。ぼかしやグラデーションは使わない。

食材と生き物を組み合わせた 36 個のシルエットを個別に定義する。例えば米粒の文鳥、豆さやのカタツムリ、わらびのカメレオン、昆布の海竜、ワッフルの柴犬、ラムネのクラゲは、それぞれ異なる体・尾・耳・翼を持つ。うまれたての粒やしずくから、手足が育つ幼体、種の特徴が現れる姿、成体、象徴的な最終形へ、体形と輪郭を変える。拡大や装飾の追加だけで段階を増やさない。

6 コレクションはそれぞれ新しいなかま 6 種・帽子 6 点・背景 6 場面を持つ。

| コレクション | なかまの例                     | 背景の例                         |
| ------------ | ------------------------------ | -------------------------------- |
| meadow       | こめぴ、かぶん、ひまり         | ピクニック丘、菜の花テラス       |
| forest       | くるね、わらも、たけのん       | 丸太の台所、竹林の茶屋           |
| seaside      | わかるん、こんぶる、こはかに   | 波止場のまかない室、帆布の屋根裏 |
| market       | ぱぷりこ、れんぷく、ぽんころ   | 朝市の八百屋、魚屋の台所         |
| cafe         | ぷるりん、もっふる、みんとっと | 町の喫茶店、コーヒー焙煎室       |
| night        | つきも、あんころ、らむのん     | 星見の食堂、提灯の中庭           |

## ファイルと再生成

- `content/expansion/characters.json`: 名前、個性、好きな料理、発見条件、4 種の台詞、成長段階、配色、装着位置。
- `content/expansion/items.json`: 名前、種類、価格、解放条件、コレクション、描画方法。
- `public/expansion/assets/characters/`: 180 個の SVG。
- `public/expansion/assets/items/`: 72 個の SVG。
- `scripts/content/generate-companions-items.py`: 設定と図形の正本。Python 標準ライブラリだけを使用する。

```sh
python3 scripts/content/generate-companions-items.py
```

設定・イラストを変更する場合はジェネレーターを編集してから再生成する。JSON や SVG の直接編集は、次の再生成で上書きされる。出力は決定的で、乱数・ネットワークアクセス・現在時刻に依存しない。

## 帽子の重ね方

帽子単体は `viewBox="0 0 300 300"`、透明背景で、既存の `Pet` の頭に合う上部座標へ描く。一覧では `renderSpec.previewCrop` にある `x=65, y=0, width=170, height=100` を切り出すと、余白を含めず帽子を見せられる。

新しいなかまの頭の位置は種と成長段階で異なる。帽子を単純に同じ座標で重ねず、選択中の段階の `renderSpec.hatTransform` を適用する。カタツムリやアルマジロのような、顔が中央にないシルエットにも対応する。

```tsx
const transform = character.stages[stage].renderSpec.hatTransform

<svg viewBox="0 0 300 300" aria-hidden="true">
  <image href={character.stages[stage].artPath} width="300" height="300" />
  <image
    href={hat.artPath}
    width="300"
    height="300"
    transform={`translate(${transform.translateX} ${transform.translateY}) scale(${transform.scaleX} ${transform.scaleY})`}
  />
</svg>
```

組み込みの葉・角・触角もなかまの特徴として残る。帽子は前景に重ね、これらを消す処理は行わない。帽子の位置は段階ごとに定義する。おとなは `HEAD_ANCHORS`、それ以外は `seed_art`・`young_art`・`signature_art` が返す頭の座標と倍率を編集して再生成する。

## 背景の重ね方

背景は `viewBox="0 0 800 600"`。中央の `x=255..545, y=215..560` をなかまのために空け、家具や植物は主に左右へ配置する。

標準的な合成は、なかまの 300 × 300 画像を幅 290 で `x=255, y=248` に置く。このときイラスト内の接地位置 `y=276` が、背景の接地位置 `y=515` におおむね一致する。帽子を加える場合は上記の 300 座標系でなかまと合成した後、全体を移動・縮小する。背景の座標系に直接帽子の変換を適用しない。

## ゲームへの取り込み

発見条件は、おとなのなかま 1〜8 匹、異なる料理 3〜80 種。好みは表示や台詞を広げるための情報として用意しており、嫌いな料理、経験値低下、食事への罰則は持たない。帽子と背景も経験値や料理報酬を変更しない。

価格と発見条件はプロトタイプ用の初期案。コイン・ジェムの獲得ペースに合わせて調整する。現在のゲームで実際に到達できるかをプレイ時間で測定したものではない。

SVG は各段階 1 表情の静止画。現在のアプリの食事中・睡眠中などの表情差やアニメーションを、これだけで置き換えることはできない。取り込み時には静止画として使うか、必要な表情を追加する。

## 検証

ジェネレーターは件数、ID と名前の一意性、5 段階からの画像参照、252 個すべての XML 構文を検証する。36 種すべての 5 段階を横並びでレンダリングし、輪郭と姿勢の変化を目視確認した。帽子 36 点、背景 36 場面、おとなと帽子を組み合わせた 36 例も作成時に確認済み。背景はなかまを中央に置いた状態で確認している。全段階と全帽子の組み合わせや、実アプリでの追加のなかまのゲームプレイは未検証。

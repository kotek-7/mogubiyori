# ナロ諸島の地理

## 六つの島と海の道

ナロ諸島は、中央のアシロ島を囲んで五つの島が浮かぶ群島である。西に森のトヌ島、南に干潟のセラ島、東に港のニカ島、北に霧のウネ島、北東に黒い岩岸のヨルバ島がある。晴れた日のアシロの尾根からは五島とも見える。島影が重なるウネとヨルバは、低く丸い稜線と、切り立った岩壁で見分ける。

アシロ東岸のカヤ村からの航路は、次のようにつながっている。距離は海上で実際に進む道のりで、時間は穏やかな海を普通の帆船で渡る片道の目安である。積み降ろしと潮待ちは含まれない。

| 行き先           | カヤ村からの方向と道筋           | 航路の長さ | 帆走時間  |
| ---------------- | -------------------------------- | ---------- | --------- |
| ニカの内港       | 東へ、入り江を出て対岸へ渡る     | 約28km     | 4〜6時間  |
| セラの北の船着き | アシロ東岸を南下して渡る         | 約34km     | 6〜8時間  |
| ウネの南の船着き | アシロ東岸を北上して渡る         | 約38km     | 7〜9時間  |
| ヨルバの西浜     | 北東へ、沖の浅瀬を南から回る     | 約42km     | 8〜10時間 |
| トヌの東の木材浜 | アシロ南端を回り、西の海峡を渡る | 約48km     | 9〜11時間 |

アシロ西岸からトヌへの海峡は狭い。カヤから出る船はアシロの南岸に沿って大きく回り込むため、急ぎの小荷物は島の西岸へ陸路で運んでから船に載せる。ニカ、ウネ、ヨルバを続けて訪ねる船も、一日に三島を回らず、それぞれの船着きで夜を越す。

初夏は雨が続き、その後は南寄りの風が多い。北へ向かう船はよく進み、南へ帰る船は帆を切り返す。秋には北西の風が入り、冬の島間航路は波の低い日を選ぶようになる。夏の終わりの強風で浜の形が変わると、船乗りは岸の杭を打ち直す。島々の距離は短くても、浅瀬と潮の向きは毎日同じではない。

## アシロ島――カヤ村と、その外

アシロは諸島で最も広く、低い尾根の両側に畑と小さな集落が散らばる。カヤ村は東向きの入り江にある四十戸ほどの村で、湾口の南北を岩の岬に守られている。砂浜は南北に約五百メートル。北半分に舟を上げ、南半分には細い流れが海へ注ぐ。干潮にはその河口だけが平たい泥地になり、小魚と小さなカニが残る。

十歳のミナが両親と暮らす家は、浜から一段上がった村道沿いにある。家の戸口から東南へ七十メートル、ゆるい坂を下ると、石を三方に積んだ屋外の炊事場「下のかまど」がある。家からは子どもの足でも二分ほどで着く。上の村道にも共同のかまどがあるので、村人は昔からこの名で呼び分けている。

下のかまどの背には薪を乾かす浅い屋根があり、海側には平たい土の庭が広がる。ミナが世話をする幼体の寝床は、火口から離れた屋根の端に置かれている。家から運んだ器を並べる低い棚と、雨の後にも乾きやすい砂利の一角がある。ホエリの成体ガロが休む庇は、庭の北隣。ミナがまだ小さい頃から、家へ帰る姿をそこから見送ってきた。今はガロに託された幼体が、かまどのまわりを歩いている。

かまどから浜までは東へ百四十メートル、三分ほど。道は網干し場の横を抜け、舟を引くための丸太が並ぶ北の砂浜へ出る。村の荷物もこの道を通るため、中央には鉢や薪を置かない。浜の南端の浅い流れまでは、そこからさらに三百メートルある。

共同の水場は、かまどの北西百八十メートル、登り道で四分ほどの所にある。尾根からしみ出す水を石の樋で受け、上の受け口で飲み水をくみ、下の槽で籠や泥のついた道具を洗う。使った水は浜の流れへ直接落とさず、草の生えた浅い溝を通る。大雨の日は水場も濁るので、家々には前日までにくんだ水を蓋つきの甕に残してある。

畑はかまどの西三百五十メートル、歩いて八分ほどの段丘にある。水場より高いため、主に雨で育つ豆、麦、かぶ、にんじんを作る。畑の上端からは、低木の間を西へ抜ける獣道が続く。そこを二十分ほど登ると、島の中央へ続く尾根道に出る。人の靴跡が少なくなる辺りで、道は人間の肩幅から、草を分けるもぐ一匹分の幅へ変わる。

春には畑の虫を追う小型のもぐが畔へ来る。秋には落ちた豆を拾う個体が増え、夜になると、それを狙う大きな鳥が柵の杭にとまる。村のもぐも野生のもぐも、水場より上の茂みでは同じ木の実を食べる。畑の外の落ち葉をすべて掃かずに残すのは、土を覆うためでもあり、虫や小さな生き物の居場所を畑の外へ残すためでもある。

村から南西へ一・六キロ、三十分ほど歩くと、水田のある浅い谷へ出る。尾根の反対側から回ってきた沢を引いており、カヤの飲み水の流れとは別である。米の収穫が済むと、刈り株の間にカエルが集まり、水辺のもぐが虫を探す。古い石積みには、今の水路より低い取水口が残る。祖父母の代の大雨で沢が曲がり、田の入口を移した跡である。

## トヌ島――木材浜、谷の森、尾根の林

トヌの東岸には、丸太を引き上げる緩い浜がある。人と大きなもぐが一緒に木を動かし、樹皮や枝を落としてからアシロやニカの船へ渡す。浜から谷沿いに一時間歩くと、湿った広葉樹の森に入る。倒木にはきのこが生え、木の内側を食べる虫を、爪で樹皮をはがすもぐが探している。

谷の流れは雨の後に太くなるが、浜の集落は少し高い横斜面の湧き水を使う。丸太を流す水と飲む水を分けているため、木を運ぶ日にも水くみは止まらない。きのこは谷、栗とくるみはさらに一時間登った乾いた尾根に多い。秋に実を埋めるもぐが掘り忘れた場所から、翌春には若木が出る。木の穴を寝床にする個体は、尾根を巡る猛禽の影が過ぎるまで顔を出さない。

森の古い運材路には、車輪の幅に削れた石が残る。谷底の道が崩れた後、人と荷を運ぶもぐは斜面の上へ道を移した。古道のくぼみは雨水をため、今では小さな生き物の水飲み場になっている。

## セラ島――北の船着き、干潟、塩場

セラは低い島で、北岸の細い深みだけが潮の低い時にも舟を寄せられる。船着きから東へ三十分歩くと、ヨシ原とアマモの浅瀬が入り交じる干潟へ出る。潮が満ちると小魚が草の間に入り、引くとカニや貝を探すもぐが出てくる。足跡の周囲に小さな穴が増えるのは、踏まれた泥へ隠れた虫を掘り出すためである。

南西の塩場は、干潟の軟らかい泥ではなく、砂と粘土が固く重なった岸にある。海水を浅い槽に取り、晴天が続く間に濃くしてから釜へ運ぶ。雨の多い初夏には塩作りが休み、釜や槽の手入れと貝の加工が増える。薪は島だけでは足りず、トヌの端材がニカ経由で届く。

島の井戸は渇くと塩辛くなる。家々の大きな雨水甕と、北岸の湧き水が暮らしを支えている。塩場の裏には使われなくなった四角い槽が残り、今は雨水のたまる草地になった。強い波で取水口が埋まった後、塩場を西へ移したのである。湿った古い槽は、乾いた夏にも小型のもぐが身を冷やせる場所になっている。

## ニカ島――内港、市場坂、東の砂州

ニカの内港は西向きの湾の奥にあり、カヤから来た船は岬を一つ回って入る。岸の近くまで水が深く、穀物や木材を積んだ船も横づけできる。港の背から市場坂が上がり、下には鮮魚と野菜、坂の中ほどには塩、干物、豆、布を扱う店が並ぶ。重い荷を運ぶもぐは、混む階段を避けて倉の裏の緩い道を使う。春には近海で群れる小魚が市場を埋め、冬に欠航が増える前には、乾物と薪の倉がいっぱいになる。

飲み水は市場より上の井戸から引く。魚を洗う水は港側の別槽へ運び、井戸の周囲へ戻さない。魚の切れ端を待つもぐには集落で暮らす個体もいるが、夜には港外の岩から野生の個体も来る。魚を追う鳥が落とした小魚をカニが食べ、そのカニを狭い石の隙間から引き出すもぐもいる。

市場から東へ四十分歩くと、風にさらされる砂州へ出る。湾内では見えなかった沖のうねりがここでは岸へ届き、嵐の後は海藻と流木が帯になって残る。砂州の付け根には低い果樹畑があり、春の花に来る虫をミツバオが追う。市場の残り物を期待する個体は夕方に港側へ戻るが、実の熟す季節には何日も顔を見せない。

ニカでは月に二度、夕方からも市が立つ。ヨルバから来る舟が暗くなる頃に着いた冬、魚を翌朝まで置くより、火を起こして売ろうとしたのが始まりだという。今は夜に起きるもぐの食事を買いに来る人もいて、市場坂には低い位置にも油灯が掛かる。昼の店が軒へしまった品の下で、別の鍋と器が並ぶ。

## ウネ島――南の船着き、茶畑の坂、峠の池

ウネの南岸は低く、奥へ入るほど山が高くなる。船着きの集落から一時間登る茶畑の坂には、海から来た湿った風が霧になる。茶の木の間に残した草は斜面の土を押さえ、葉を食べる虫の居場所にもなる。虫を拾う小型のもぐは、摘み手の籠をのぞいてから、また木の下へ戻る。

坂の上、さらに四十分ほどの峠には浅い池がある。霧と雨を受けた斜面の水が集まり、細い沢になって南へ下る。集落の水車と醸造小屋はこの流れ沿いにある。山側の水と、セラから届く塩、アシロの米や豆が、ここで味噌や漬物になる。小屋の床は湿った地面から高く離され、器を乾かす棚は風の通る南側にある。

池では春にカエルが増え、夏にはそれを追う水辺のもぐが岸を歩く。冬は霧が薄くなり、落葉した林の中に古い茶畑の石段が見える。摘んだ葉を蒸す小屋が村へ集まった後、運ぶ間に葉を傷めやすかった上の畑を休ませ、近い斜面へ植え直した跡である。

## ヨルバ島――西浜、黒い岩棚、山腹の洞

ヨルバの西浜は、黒い岩壁の切れ目にある小さな砂浜である。上陸した船は、波の届かない高さまで引き上げる。浜から南へ二十分歩くと、古い溶岩が幾段にも割れた岩棚が続く。昼に熱をためた石は夕方も温かく、日中は隙間に隠れていた虫と、薄暗がりに強いもぐが出てくる。もぐが鼻先で石を押すと、下の虫が隣の割れ目へ逃げ込む。

浜から内陸へ五十分登る山腹の洞は、かつて流れた溶岩の内側が空いた場所である。秋の北風とともに渡り鳥が来て、洞の入口近くで羽を休める。鳥の落とし物と風で入った葉が、薄い土を少しずつ作っている。洞の外縁には草が根を張り、種を食べる小型のもぐが集まる。夜に狩るもぐは、その草地と岩棚の間を巡る。

島では雨が岩の割れ目へすぐ消える。西浜の住人は屋根で雨を集め、谷の細い湧き水と併せて使う。畑は岩を除いた小区画に限られ、豆といもを育てる。夕方は炉の火を消す家と、これから火を入れる家が半々ほどになる。人々は雨戸の裏へ白い布を掛け、今起きている家を浜から見分けられるようにする。

黒い岩棚のくぼみには、みつるが通った後にも琥珀色の筋が残ることがある。光は水面より底の石に濃く見え、朝には消えている。海水ごと器へすくっても、持ち帰る間に消える。西浜の子どもはこれを「海の寝返り」と呼ぶ。祖父母から同じ呼び名を聞いた大人も、光の長く残る晩をうまく言い当てられない。

夜の浜には家の灯りと舟の灯りがあり、岩棚の低い光はそれらよりさらに下に見える。宵の芋粥を持って浜へ出る人は、灯りを高く掲げず、足元の石を一つずつ確かめて歩く。

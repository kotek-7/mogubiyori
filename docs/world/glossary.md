## 六種と個体名

種の名と、ミナたちがつけた個体の名は区別される。ガロとこむぎは同じホエリであり、年齢と体つきが大きく違う。

| 種名           | 身近な個体名 | 主な特徴                                                             | 詳細                     |
| -------------- | ------------ | -------------------------------------------------------------------- | ------------------------ |
| ホエリ〈穂襟〉 | こむぎ、ガロ | 首を穂状の束毛が囲む。里山の種子食寄りの雑食で、幼体の集まりを見守る | [もぐ誌](mog-species.md) |
| ヤブミミ       | まめ         | 葉脈のような血管の走る大耳。草や柔らかい樹皮を食べ、藪の縁に暮らす   | [もぐ誌](mog-species.md) |
| ミズワタリ     | しずく       | 幼体の雫形から長い首と脚の鳥型へ育つ。浅瀬で虫などを探す             | [もぐ誌](mog-species.md) |
| ミツバオ       | ゆず         | 育つと三本に分かれる尾を持つ。果樹林で実や虫を探し、殻などを交換する | [もぐ誌](mog-species.md) |
| カゲネ         | もも         | 桃色と灰色の毛を持ち、根や岩の影を渡る。小動物を捕る                 | [もぐ誌](mog-species.md) |
| イワメ         | ごま         | 岩壁に暮らす夜行の鳥型。巣口の小石の音で来訪を知る                   | [もぐ誌](mog-species.md) |

ほか三十六種の通称と生息地は、[もぐ誌の名簿](mog-species.md#名簿)にまとめている。

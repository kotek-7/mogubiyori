# もぐ日和の体験検証

## 確かめたいこと

こむぎにごはんをあげたい気持ちが、実際に自炊を始める理由になるか。写真提出が負担にならず、忙しい日を挟んでも戻ってこられるかを観察する。

## 15分のセッション

1. **生活を聞く（3分）**：直近で自炊できた日と、やめた日を聞く。時間・食材・気力のどこに負担があったかを具体的にする。
2. **説明せず遊ぶ（4分）**：料理を作り終えた場面から、ごはんをあげ、食後のおへやに戻ってもらう。写真がなければサンプルを使う。
3. **明日と休んだ後を試す（4分）**：設定で日付を進める。空腹やストリークへの反応を聞き、今日何をしたくなるかを観察する。
4. **着せ替える（2分）**：所持通貨でアイテムを選んでもらう。欲しい理由と、選ばない理由を聞く。
5. **振り返る（2分）**：明日も開きたいか、それが自炊にもつながりそうかを分けて聞く。

## 再現する場面

| 場面                   | 試す操作                     | 観察すること                           |
| ---------------------- | ---------------------------- | -------------------------------------- |
| 初めて会う             | 設定からまっさらな状態にする | 自炊で育つゲームだと伝わるか           |
| 料理を作った           | 写真だけでごはんをあげる     | 迷わず一周できるか、反応がうれしいか   |
| 今日もう一度作った     | 2件目を記録する              | 追加報酬がなくても記録する価値があるか |
| 翌日になった           | 日付を1日進める              | 表情と催促が、料理のきっかけになるか   |
| 忙しくて作れない       | チケットを使い、翌日に進める | 保護と空腹の違いが伝わるか             |
| 作れない日が続いた     | 記録せず2日進める            | 責められたと感じずに再開できるか       |
| もう少し急かしてほしい | リマインドの口調を切り替える | 行動したくなるか、通知を止めたくなるか |
| 部屋を変えたい         | 購入して着せ替える           | 成長と愛着につながるか                 |
| ジェムの品が欲しい     | 試用のジェム追加後に購入する | 有料で欲しい理由があるか               |

日付変更は実際の日付への加算として保存される。リセットはこのゲームの記録や育成状態を初期化するため、写真を残したい場合は別のブラウザで試す。

## 記録する項目

- 最初に押した場所、写真選択から食後のおへやまでの時間
- 空腹・成長・ストリークのうち、本人が自然に気づいたもの
- 「アプリを開きたい」と「料理を作りたい」のそれぞれの理由
- 忙しい日の後に戻りたいか、戻りたくない理由
- アイテムを選んだ理由、普段のゲームでの購入経験、実際に払える金額

行動・本人の発言・観察者の解釈を分けて記録する。口調を比較するときは、同じ日付・空腹状態に揃える。

## 継続を確かめる試験

短い操作体験では、継続率や課金意欲を証明できない。次は2週間程度の利用で、週あたりの自炊日数、翌週の再訪、未記録日の後の復帰を追う。登録前の自炊頻度と本人の生活予定も合わせて確認する。

写真提出数だけでは自炊が増えたとは言い切れない。もともと料理していた日と、このゲームがきっかけになった日を聞き分ける。試用通貨で買った数を、実際の売上予測として扱わない。

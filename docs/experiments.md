# もぐ日和の体験検証

## 確かめたいこと

なかまの成長と収集の楽しさが、自炊を始める理由になるか。ゲームを開きたい気持ちと、料理を作りたい気持ちを分けて観察する。

## 15分のセッション

1. **生活を聞く（3分）**：直近で自炊できた日と、やめた日を聞く。時間・食材・気力のどこに負担があったかを具体的にする。
2. **説明せず遊ぶ（4分）**：最初のなかまを選び、ごはんをあげてもらう。何を目指したくなったか、本人の言葉で聞く。
3. **成長と出会い（4分）**：設定の「成長・出会いを体験」から料理をあげ、来客を迎える。育成対象を増やしたいか、負担と感じるかを見る。
4. **次の一皿を選ぶ（2分）**：料理ずかんでレシピを選ぶ。カードの報酬が、自分に作れそうな料理を選ぶ助けになるかを聞く。
5. **振り返る（2分）**：明日も開きたいか、自炊にもつながりそうかを分けて聞く。

## 再現する場面

| 場面             | 試す操作                            | 観察すること                                 |
| ---------------- | ----------------------------------- | -------------------------------------------- |
| 初めて会う       | 「最初から育てる」から選ぶ          | 選ぶ理由が生まれるか                         |
| 自炊した         | 写真を届ける                        | 入力が負担にならず、成長がうれしいか         |
| 初めての料理     | レシピを選んで記録する              | カードと報酬の意味が伝わるか                 |
| 同じ料理が続く   | 同じ相手に同じ料理を3回あげる       | 別の料理を試したいか、自炊自体が嫌になるか   |
| おとなに育つ     | 「成長・出会いを体験」から1回あげる | 姿の変化と来客が次の目標になるか             |
| お客さんが来る   | ごはんを分けて迎える                | なかまになった実感があるか                   |
| 忙しくて作れない | チケットを使い、翌日に進める        | 保護と空腹の違いが伝わるか                   |
| 作れない日が続く | 記録せず2日進める                   | 再開する一歩が見つかるか                     |
| 催促を変えたい   | 口調を切り替える                    | 行動したくなるか、閉じたくなるか             |
| 着せ替えたい     | コイン・試用ジェムで購入する        | 愛着につながるか、有料でも欲しい理由があるか |

日付変更は実日付への加算として保存される。リセットは写真・育成・収集状態を初期化するため、記録を残したい場合は別のブラウザで試す。

## 観察する項目

- 最初に選んだなかまと、その理由
- 写真選択から給餌完了までの時間と、迷った場所
- 成長・新しいなかま・料理カードのうち、次に追いたくなったもの
- 同じ料理の経験値減少が、自炊をやめる理由にならないか
- 忙しい日の後に戻りたいか、戻りたくない理由
- アイテムの選択理由、普段のゲームでの購入経験、払える金額

行動・本人の発言・観察者の解釈を分ける。口調を比較するときは、日付・空腹・なかまの状態を揃える。

## 継続の試験

短い体験だけでは継続率や事業性はわからない。次は2週間程度の利用で、週あたりの自炊日数、翌週の再訪、未記録日の後の復帰を追う。利用前の自炊頻度と生活予定も合わせて確認する。

写真提出数だけでは自炊が増えたとは言い切れない。もともと料理していた日と、このゲームがきっかけになった日を聞き分ける。試用通貨での購入数を売上予測として扱わない。

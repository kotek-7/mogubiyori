# 食事管理・自炊の継続に関する公開体験調査

調査日：2026年9月25日。対象プロダクト：もぐ日和。

**課金して食事管理に取り組んでも、入力や心理的な負担で続かないという公開体験は複数確認できた。大学生が自炊を続けられないという本人の体験も確認できた。ただし、この二つを同一人物について確認できる日本の一人暮らし大学生の投稿は、今回の採用資料にはない。**

この資料は、課題の存在を説明するための質的な証拠集である。対象人数や離脱率を測る調査ではない。投稿者の実在、課金履歴、体験の真偽を本人に再確認したものでもない。

全件の出典・短い原文・日付・属性・留保は [体験台帳](evidence.md)、検索や絞り込みに使えるデータは [JSON](evidence.json)、検索式・取得できなかった媒体・除外理由は [探索記録](search-log.md) に収録した。

67検索式で媒体を横断し、**体験・回答48件と運営一次資料1件、出典ページ群40件**を採用した。48件には中断、契約終了、負担のみ、再開、継続の反例を含むため、48人の離脱者を確認したという意味ではない。

## 繰り返し現れた負担と、その解釈

1. **料理した後に、さらに記録の仕事が発生する。** 自炊の材料、調味料、取り分、前日の残り物などを入力する負担がある。多様な料理を作ることと、精密な記録を続ける難しさを結びつける声もある。[S01](https://minhyo.jp/asken?page=2)、[ALT11](https://www.reddit.com/r/loseit/comments/146et4p/for_those_of_you_that_use_a_calorie_tracker_app/)、[ALT01](https://ameblo.jp/natuly723/entry-12607960816.html)
2. **厳密に記録できないこと自体がストレスになる。** 正確に残そうとする気持ちが、入力の手間や欠けた記録への不満を大きくする例がある。[ALT02](https://note.com/s_ptwh/n/nb3ffbefe0d4d)、[ALT11](https://www.reddit.com/r/loseit/comments/146et4p/for_those_of_you_that_use_a_calorie_tracker_app/)
3. **点数・表情・助言を、支援よりも叱責として受け取る場合がある。** 楽しい食事を評価されることや、否定的な表情に気持ちが左右されて中断する例。全利用者に同じ反応が生じるという意味ではない。[B05](https://note.com/sushiparty/n/n1064b4f344d9)、[S09](https://apps.apple.com/jp/app/1275952220?platform=iphone&see-all=reviews)
4. **払った料金に見合う成果・便利さを感じられない。** 課金を続ける動機が弱くなる一方、これは調理負担に限らない。[B03](https://note.com/chottokokorade/n/n98eafce873bf)、[B06](https://tomituku.com/living/asken-ending)
5. **自炊の継続には、記録以外の負担もある。** 学生本人の話では、買い物・片付け・食材の使い切り・夜勤や授業との両立が挙がる。[U01](https://kindaipicks.com/article/002618)、[U02](https://witchverse.hatenablog.com/entry/2019/02/12/221719)、[U03](https://banabou.com/continue_self-catering/)

これらから、料理を記録しやすくすること、できた行動を肯定的に振り返れることには検証する理由がある。ただし、写真の誤認識も離脱理由に挙がるため「写真にすれば解決」とはいえない。料理する時間そのものが足りない人にゲームが役立つかは、別途確かめる必要がある。

## 一緒に提示すべき別の経験

- **既存アプリでも、親しみやゲーム感覚が継続理由になっている。** SOC12は一人暮らしで、帰宅時の挨拶や高得点を目指す楽しさを評価。U04の大学生もゲーム感覚で使っている。「既存サービスには楽しさがない」という説明は避ける。[SOC12](https://girlschannel.net/topics/4164233/)、[U04](https://serenday.jp/article/kenko-otakukun/)
- **入力負担があっても、課金機能を活用して続く人がいる。** S11は定番登録等を活用し、S12は約2年有料利用を継続している。[S11](https://app-liv.jp/865649/reviews/?cur_page=2)、[S12](https://minhyo.jp/asken)
- **離脱は、食生活を諦めたことと同じではない。** SOC02・ALT01・ALT09は食事の傾向を把握できた側面があり、B07は別の記録手段に移行し、自炊頻度は増えたと述べる。[SOC02](https://girlschannel.net/comment/5894606/122/)、[B07](https://nene.tokyo/rundiet1/)
- **運営も負担を認識し、改善している。** askenは2022年に、自炊利用者の入力負担を背景としてWebレシピ読込を有料版へ導入したと説明している。これは独立口コミではなく企業の一次資料で、課題認識と既存の対策を示す。[O01、公式PDFの2ページ目](https://www.asken.inc/s/PressReleaseWeb.pdf)

## 発表に使える説明文

次の文章は調査結果の要約であり、誰か一人の直接引用ではない。

> 食生活をよくしたいと思い、食事管理アプリに課金しても、記録の手間や心理的な負担から続かないという公開体験があります。また、大学生本人からは、健康的な食事を作りたい一方で、買い物や調理、片付けを続ける難しさも語られています。もぐ日和では、一人暮らしの大学生を初期対象として、料理したことを小さな楽しみに変える体験を検証します。

この文章の出典として、課金後の中断には **SOC03またはALT02**、学生の調理負担には **U01とU03** を組み合わせる。それぞれ異なる人の話であることが伝わるようにする。

現在の狭いペルソナを説明する場合は、「公開口コミで一人暮らし大学生の課金後離脱まで立証済み」とせず、**食事管理の中断経験を持つ人という課題仮説と、一人暮らし大学生という初期対象を分けて説明する**のが、この調査の証拠に合う。

## 残る確認事項

今後のヒアリングでは、課金経験の有無だけでなく「最後に記録した日」「最後に自炊した日」「それぞれをやめた直接のきっかけ」「今の代替手段」を別々に聞くと、記録の問題と調理の問題を混同しにくい。さらに、写真の修正や育成の操作を含めても本人が負担を感じないか、使わなかった翌日に戻れるかを実際の利用で確かめる必要がある。

この調査で支持されたのは、公開体験として語られる課題の存在と、その具体的な形である。ペルソナの規模、支払意思、もぐ日和による継続改善は未検証である。

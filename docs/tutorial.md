# チュートリアル設計

## 目的

初めて遊ぶ人が、自炊の記録から成長・出会い・収集・継続へつながる仕組みを操作で理解できるようにする。説明を読み進めるだけでなく、各画面で一つの操作を完了し、目に見える結果を確かめてから次へ進む。

最初のなかまを選んだ後に開始する。画面には進み具合と「操作の練習」を表示する。キャラクターは言葉を話さず、姿や動きで反応する。操作ボタンは動作、見出しや結果表示は仕組みと変化を伝える。

## 5画面の操作と結果

| 画面                          | 操作                                                                       | 確かめる結果                                                                                           |
| ----------------------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| 1. 自炊でなかまを育てよう     | 「ごはんをあげてみる」を押す                                               | 料理の例を食べて満腹になり、+45 XPと成長ゲージの増加を表示する。姿はうまれたてのまま。                 |
| 2. 育つと姿が変わる           | 「育った姿を見る」「もっと育った姿を見る」を順に押す                       | うまれたて→ちびっこ→わんぱくと輪郭が変わる。5段階のうち残る2段階は未発見として示す。                   |
| 3. お客さんをなかまにしよう   | 2匹のお客さんから1匹選び、「{名前}にごはんをあげる」を押す                 | 選んだ相手にハートが現れ、仲間になった結果を表示する。                                                 |
| 4. 料理を集めて図鑑を埋めよう | 未獲得のカレーのカードを押し、レシピを確認して「カードの獲得を見る」を押す | カレーのイラストと初回カード報酬の70コインを表示する。隣の未獲得カードで収集の余地を示す。             |
| 5. まずは3日続けてみよう      | 「翌日のごはんを記録する」を2回押す                                        | 1日→2日→3日と記録が埋まり、3日連続ボーナスの30コインを表示する。毎日のログイン報酬20コインも案内する。 |

仲間とカードの画面では、操作を終えると「つづける」が現れる。最後は「はじめてのごはんへ」で本編の写真入力へ進み、「あとで記録する」ならひろばへ戻る。終了しただけでは食事を記録しない。

材料・調理時間・作り方とカード報酬は本編と同じレシピ定数を参照する。レシピの詳細はスクロールでき、作り方は折りたたむ。操作はクリック・タップ・キーボードで可能とし、ドラッグを必須にしない。選択状態と結果は支援技術にも伝え、動きを減らす設定に対応する。

## 練習と本編の分離

練習の食事、成長、加入、カード獲得、連続日数は画面内の一時状態で表現する。本編の給餌処理は呼ばず、XP・食事履歴・仲間・カード・通貨・日付・ストリークを更新しない。通常のログイン報酬はチュートリアルの報酬とは別に扱う。

永続化するのは `GameState.tutorial` の `version: 1`、`step: 0〜4`、`status`。新規ゲームは `active` で始め、なかまの選択後に表示する。本編の初回記録は通常どおり45 XPで、最初の姿のまま。練習で見た成長や加入は付与しない。

## 一時停止と復帰

| 状態        | 表示と復帰                                                                                                               |
| ----------- | ------------------------------------------------------------------------------------------------------------------------ |
| `active`    | 現在の画面を表示する。再読み込み後も保存された `step` から始める。                                                       |
| `paused`    | 中断ボタン・「ひろばを見てみる」・Escapeで移行する。ひろばまたは設定の「チュートリアルを続ける」から同じ画面を再開する。 |
| `completed` | 最後まで体験すると移行する。自動表示せず、設定の「チュートリアルをもう一度」から再生できる。                             |

保存は画面単位。中断・再読み込み・前の画面への移動では、その画面内の操作結果を初期状態に戻す。再開時に前の操作を覚えていなくても、その場の操作からやり直せる。

チュートリアル情報を持たない既存セーブは、すでに仲間がいれば `completed` として扱う。既存の進行を中断して自動表示しない。完了後の再生は一時的な状態で動かし、完了フラグを戻さず、終了時はひろばへ戻る。

## 公式資料の観察と本作の判断

以下は設計の参照であり、チュートリアルの効果を実証するデータではない。

- **任天堂で確認できること:** 開発者インタビューでは、小さな機能を完成させる体験の積み重ねと、中断後もその場の指示で進める設計を説明している。[『はじめてゲームプログラミング』開発者インタビュー](https://www.nintendo.com/jp/interview/awuxa/03.html) **本作の判断:** 各画面で操作と結果を一組にし、画面単位で再開できる構成にする。
- **Pikmin Bloomで確認できること:** 公式ヘルプでは、エキスを与えると花が咲き、花びらを集め、その花びらを花植えに使う連鎖を説明している。[Pikmin Bloomのあそびかた](https://niantic.helpshift.com/hc/ja/23-pikmin-bloom/faq/2854-how-to-play-pikmin-bloom/) **本作の判断:** ごはんをあげる→反応を見る→XPやカードを得る、という操作と結果のつながりを先に体験させる。
- **Pokémon Sleepで確認できること:** 公式サイトでは、夜の睡眠記録、朝の寝顔収集、昼のカビゴン育成を一日の循環として紹介している。[Pokémon Sleepの一日](https://www.pokemonsleep.net/pokemon/) **本作の判断:** 自炊記録を成長・収集につなげ、最後に3日間の記録を試して次の自炊へ結びつける。

これらの理由や参照元は設計資料に留め、ゲーム画面の説明を増やすためには使わない。

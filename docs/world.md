# もぐ日和 世界設定集

## ナロ諸島

ナロ諸島は、六つの島とその間の小さな岩礁からなる。中央のアシロ島では麦と豆を作り、西のトヌ島からは木材、南のセラ島からは塩が届く。東のニカ島の港に荷が集まり、北のウネ島では茶を摘み、穀物を醸す。北東のヨルバ島は黒い岩の多い島で、夕暮れから動き始める生き物が多い。

島を渡るには帆と櫂の舟を使う。近い港まで半日、遠い浜なら一日かかり、風が変われば帰りが数日延びる。島々は互いの姿が見えるほど近いが、同じものが採れるわけではない。セラの釜で使う薪にはトヌの木の端材が交じり、ウネで仕込む味噌にはアシロの豆とセラの塩が入る。

人間の集落は、水をくめる場所と舟を寄せられる岸にできた。その外には、もぐの通り道、巣、群れの水場が続く。人の道と重なるところには、爪で磨かれた柵や、人の手では届かない高さの雨宿りの跡がある。

## カヤ村とミナ

アシロ島の東岸にあるカヤ村は、四十戸ほどの集落である。湾を挟む二つの岬が波を弱め、低い段丘の上に畑がある。家々の壁には、砂粒の見える黄土色の土が塗られている。雨戸は濃い青や赤茶に塗り直され、下端ほど潮で色が削れている。屋根の修理には同じ色の板がそろわず、晴れた日は継ぎ目ごとに違う影が落ちる。

十歳の少女ミナは、器を作る母サヨ、舟を直す父オルと、浜の上の村道に住んでいる。家から七十メートルほど坂を下った「下のかまど」が、もぐと食事をする場所だ。濡れた薪を乾かす屋根、器を置く低い棚、砂利を敷いた庭があり、火口から離れた端には幼いもぐの寝床がある。

庭の北隣には、大きなホエリのガロが休む庇がある。ミナが生まれる前から村に暮らし、浜で荷を動かすときには太い肩を貸してきた。幼いミナは、昼寝をするガロの腹に背を預けて、母の仕事が終わるのを待っていた。

今はガロが見守っていた幼体の一食を、ミナが用意している。ガロは幼体を庭まで連れてきて、ミナの器のそばで待つようになった。ミナが食べ終わるまで見ていると分かってからは、食事の途中に浜へ下りることもある。ガロの子に限らず、村の周りで育ついくつかの種の幼体が、この庭に出入りする。

## もぐとは

「もぐ」は、一つの種の名前ではない。ナロの人々は、成長に伴って体形が大きく変わり、道具や身振りを覚えて暮らす生き物をまとめてこう呼ぶ。毛のあるもの、羽のあるもの、水辺にすむものがいる。島の魚や虫、普通の野鳥のすべてを、もぐと呼ぶわけではない。

種によって、人に近づく理由も異なる。ホエリは同じ場所で食事をする顔ぶれを覚え、ヤブミミは採食の道を群れで受け継ぐ。ミズワタリは岸に差した小枝で休み場所を作り、流れの向きを確かめる。器を運ぶ個体もいれば、器を渡しても縁をかじるだけの個体もいる。

もぐ同士は声、姿勢、匂い、触れ方で伝え合う。人の言葉も、よく聞く名前や動作の合図を覚えることはあるが、人間のような会話はしない。ガロが戸口に鼻を押しつけ、浜の方を向き直ると、オルは舟を上げる手伝いを求めているのだと分かる。馴染みのない人には、ただ何かを嗅いでいるように見える。

「こむぎ」「まめ」「しずく」は、ミナたちが身近な個体につけた呼び名である。種の名前はそれぞれホエリ、ヤブミミ、ミズワタリという。市場で通じる名前と島の古い呼び名が違う種もあり、旅先では姿を描いて確かめることがある。

## 人と暮らすもぐ、野に暮らすもぐ

人間ともぐが食事を分ける習慣は、今の村人の祖父母が幼かった頃にもあった。幼体の細い顎では崩しにくい種子を、人は煮たり、挽いたり、すりつぶしたりできる。年を重ねたもぐは、湿った丸太を引く、流れのある浅瀬を渡る、崖沿いの道を見つけるといったことで人を助ける。

食事と手助けの間に、その都度の勘定はない。ガロが浜へ下りない日には人が滑車を使う。ミナが熱を出せばトキが食事を用意し、幼体が採食を覚えるまでは、成体も餌場へ連れていく。村には、人と深く暮らすもぐ、季節にだけ来るもぐ、遠くから見るだけのもぐがいる。

野生のもぐは、親や群れと暮らしたり、その種の餌場で採食したりして育つ。巣に食べ物を運ぶ種も、幼いうちから別々に餌を探す種もいる。人の料理を一度も食べずに成体になるものは多い。

村の外では、もぐもほかの生き物の餌になる。小型のもぐを狙う鳥もいれば、魚や小動物を捕るもぐもいる。カヤの人々は暗くなると幼体の寝床に格子戸を下ろす。昼には開いていた畑の柵も、豆が熟す頃には夜だけ閉じる。親しい相手であっても、畑のものを好きなだけ食べさせるわけにはいかない。

## 食事と成長

食べる相手に合わせて、同じ鍋から取った食材の大きさ、硬さ、水分、温度を変えることを「口合わせ」という。ミナは家と同じ麦や根菜を使いながら、ホエリには崩して浅い器へ、ミズワタリには水気を残して底の広い器へ取る。料理を覚えることと、その個体の食べ方を覚えることは、カヤでは近い意味を持つ。

もぐは成長の節目に、体つきが大きく変わる。羽が生え替わる、短い脚が伸びる、体を包んでいた柔らかな毛が抜けるなど、変化の仕方は種ごとに違う。変化の前にはよく眠ったり、器に口をつける位置が変わったりする。いつ起こるかは、種や個体、生まれた季節によって違う。

カヤでは姿の移り変わりを五つに分けて話す。「うまれたて」「ちびっこ」「わんぱく」「おとな」「とっておき」である。最後の呼び名は老いたものを指さず、成体になってからその種らしい体が十分に整った姿を指す。静かな個体でも「わんぱくの頃」と言われることがある。どれも世話をする人たちの生活の中でついた呼び方だ。

人の食事は、野生では限られた時期にしか得られない柔らかさや食べやすさを用意できる。一方で、巣材の集め方や水中での足の運びは、食事だけでは身につかない。ミナの庭で育つ幼体も、ガロや同じ種の成体について、庭の外へ出ていく。

## 島で残るもの

家々には祖父母から使う鍋があり、もぐの通り道には人が直すのをやめた古道がある。使わなくなったセラの塩槽には雨水がたまり、ウネの茶畑の石段は林の下に隠れている。古い仕事の跡は、後から来た生き物の水場や寝床になっている。

カヤでは、出ていったもぐの器を、ひと冬は棚の奥にしまっておく家が多い。戻ってくるものも、春に別の幼体を連れてくるものも、戻らないものもいる。欠けた器を花鉢にした家もあれば、何年も磨いている家もある。

夕方、ミナが下のかまどの灰を寄せると、ガロは庇の下で体の向きを変える。潮の匂いに、煮た豆と湿った薪の匂いが混じる。浜から上がってくる足音のうち、どれが父で、どれがもぐなのか、ミナには姿が見える前から分かる。

# もぐ日和の世界設定

島々に、人間ともぐが暮らしている。人間は幼いもぐの食事を作り、大きいもぐは力や体の特性を生かして人間の暮らしを支える。集落に住む小さな少女も、この関係の中で育ってきた。顔見知りの大きいもぐから幼体を託され、今は自分が食事を作って世話をしている。

## 島々と集落

舞台は、森、海辺、港、市場など、自然と人の営みがつながる島々。少女には集落に帰る家があり、その周囲の屋外でもぐと過ごし、食事を分ける。ここが暮らしの拠点になる。

世界の広がりを考える際は、未知の場所との出会いを中心に置き、その土地の生き物、そこで営まれる暮らしへと関心をつなげる。生息環境と体の形、食べるものと行動、人と関わる距離には、それぞれ理由がある。

もぐの暮らしは、少女が訪れる前から続いている。集落の周囲にも、その外にも、互いに関わりながら生きるものたちがいる。

## もぐ

もぐは、島々に生息する生き物たち。種によって形、食性、習性、社会性が異なる。簡単な道具を使う、物を交換する、群れの習慣を受け継ぐなど、独自の暮らしを持つ。すべての種に同じ知性や生活様式を当てはめない。

かわいさには、少し変わった体形や癖と、動物としての振る舞いの両方がある。姿だけでなく、何を好み、何を避け、どこで休み、ほかの個体とどう関わるかが、その種らしさを作る。

食材を思わせる姿は、一部の種の特徴として扱う。すべてのもぐを食材と動物の組み合わせにする必要はない。種ごとの形は、生息環境や暮らしからも考える。

野生のもぐも、自分たちの環境で食べ、育つ。人間に育てられることは、もぐ全体の生存条件ではない。人と暮らす個体には、食事や経験を通して育まれる関係と、その暮らしに応じた育ち方がある。

## 人間との共生

人間は、火や道具を使い、食材を組み合わせて食事を作る。大きいもぐは、人間には難しい力仕事や移動などを、それぞれの体の特性で助ける。人間ともぐは、互いにできることを持ち寄って暮らしている。

幼いもぐの食事を人が用意し、大きいもぐが人間の暮らしを支える関係は、世代をまたいで続く。大きいもぐに見守られて育った人間の子が、やがて幼いもぐの世話を覚える。

この共生は、人と関わるもぐの暮らしを支える。野生で完結する生態も同じ世界にあり、人との関係の深さは、種や個体、土地によって異なる。

## 料理の位置づけ

料理は、日常の生活技術であり、もぐについて蓄積された知識を扱う技術でもある。子どもも簡単な食事から覚えられる。種や成長段階による違いをよく知る料理上手や専門家もいる。

食材を加工することで、幼いもぐにも食べやすく、体に取り込みやすい食事になる。調理で引き出される食材の性質と、もぐの成長との関係も、種ごとの生態を考える軸とする。具体的な作用は各種の設定で定め、全種共通の魔法や数値ルールとしては固定しない。

一皿の後ろには、その土地で手に入るもの、食べる相手の体、人々が受け継いできた作り方がある。少女が料理を作ることも、この文化の中で身につけていく暮らしの一部である。

## 少女と最初のもぐ

主人公は、集落に暮らす小さな女の子。帰る家があり、周囲の人やもぐとの関係の中で暮らしている。

最初に世話をする幼体は、少女が幼い頃から顔見知りだった大きいもぐに託された子。かつて見守られる側だった少女が、今度は幼いもぐの食事を作り、その成長を見守る。

この経緯は、現在の暮らしを支える背景として扱う。託される場面の導入演出は追加せず、すでに食事と世話を重ねている日常から始められる。

## 世界の深みと表現

親しみやすい雰囲気とかわいさを保ち、その奥に、生態や暮らしのつながりを持たせる。自然には捕食、縄張り、環境への適応といった厳しさもあり、もぐたちはそれぞれの事情を持って生きている。

深みは、個々の形や行動、場所の成り立ちに筋が通っていることから作る。すべての設定が画面で説明される必要はない。世界全体を貫く大きな謎、真相の解明、サスペンスを物語の核として置くことは、この設定の目的に含めない。

## 制作への適用

この資料は、キャラクターの設定、背景、美術、動作を考える共通の土台とする。設定の項目を、そのまま新機能、イベント、説明文へ置き換える必要はない。

今後の個別設定では、生息環境、食事、体の特徴、他の生き物との関係、人間との距離をつなげる。既存のキャラクター設定や拡張素材も、この共通設定を基準に整える。

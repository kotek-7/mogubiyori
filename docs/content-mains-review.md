# 主菜・副菜レシピの内容確認

対象は `content/expansion/recipes/mains-sides.json`。主菜75品、副菜75品、計150品を収録している。全品1人分で、材料は計1,185項目、手順は計526段階。材料の組み合わせから機械的に種類を増やさず、料理ごとに分量・調理法・仕上がり・コツを記述した。

## 内容の幅

- 主菜：鶏・豚・牛、鮭・青魚・白身魚、えび・いか・貝、豆腐・厚揚げ・高野豆腐、豆、卵、野菜。炒め物、煮物、蒸し物、揚げ物、オーブン料理、包む料理を含む。
- 副菜：根菜、葉物、豆、きのこ、海藻、卵、豆腐、練り物。温かい小皿、あえ物、サラダ、浅漬けを含む。
- 時間には、記載した水切り・漬け置き・冷却も含めた。海鮮チヂミだけは材料を「解凍済み」と明記し、冷凍品を使う際は事前解凍が必要とコツに記載している。
- 肉・魚・卵は中心まで加熱する手順を記述。生食するたこ・もずく・めかぶは、加熱済み・そのまま食べられる材料を指定している。
- 絵の指定は料理に含まれる具・薬味と一致させ、切り身、串、丸い肉団子、袋、扇形のいも、れんこんの輪切りなど、料理の形の違いも指定した。赤・緑・黄金色・茶色を軸に、くっきりした色を使っている。

## 検査結果

`python3 scripts/content/author-mains.py` から完成JSONを再生成できる。

- 件数、カテゴリ内訳、ID・料理名の一意性、1人分、正の所要時間、手順数、タグ数、材料名の重複、報酬と難易度の対応を確認。
- 画像用の色が16進カラーコードであること、具・薬味・形の識別子形式を確認。
- 全526段階で、完全に同一の手順文の使い回しは0件。
- 主食等の別ファイル `staples.json` と比較し、ID・料理名の重複は0件。
- 材料名と手順の照合で残った24項目は「ツナ水煮→ツナ」「しめじ・えのき→きのこ」などの言い換えで、使用漏れではないことを確認。
- 別担当の内容確認で見つかったスペイン風オムレツとシャクシュカ相当料理を、鶏肉とカシューナッツの炒め物・うずら卵と豚肉の八宝菜へ差し替えた。さらにハッシュブラウンと調理内容が近いじゃがいものガレットを、ハッセルバックポテトへ差し替えた。

実際の調理検証は未実施。加熱時間は材料の厚み・器具で変わるため、手順の「中心まで火を通す」「竹串が通る」といった仕上がりも併せて確認する内容としている。栄養値、医療効果、アレルゲン不使用の保証は設けていない。

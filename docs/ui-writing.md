# もぐ日和のUI文言

プレイヤーは自分の料理を記録して、ひろばの生き物を育てる。こむぎたちは人語で話さず、表情と動作で反応する。システムが操作・状態・結果を表示する。この役割分担をすべての画面で保つ。

## 用語と呼び名

画面見出し、タブ、操作説明、読み上げラベル、仕様書で、本作の同じ対象には同じ表記を使う。拡張ずかんとチュートリアルもこの表に従う。

| 対象                 | 統一表記               | 揺れていた表記・使い分け                                                                                                                         |
| -------------------- | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| 主画面               | ひろば                 | 「ごはんのひろば」「ホーム」を画面名として使わない。背景アイテムの「いつものひろば」などの固有名は保つ。                                         |
| 収集画面             | ずかん                 | 「図鑑」「料理図鑑」も、本作の画面名では「ずかん」に揃える。                                                                                     |
| 購入画面             | おみせ                 | 「ショップ」「お店」を画面名として使わない。ジェム用の画面は「ジェムのおみせ」。                                                                 |
| 食事の履歴画面       | ごはんの記録           | 「アルバム」は画面名として使わない。保存データを説明する「食事履歴」とは区別する。                                                               |
| 集めるカード         | 料理カード             | 「レシピカード」「料理のカード」を使わない。対象が明らかな詳細画面では「カード」と省略できる。材料・手順を指すときは「レシピ」。                 |
| 一緒に暮らす相手     | なかま                 | 「仲間」「なかまたち」を機能名に使わない。加入前は「お客さん」、生き物の総称は「もぐ」。                                                         |
| 育てる操作           | おせわ                 | 「お世話」を機能名に使わない。                                                                                                                   |
| 衣装の変更           | きせかえ               | 「着せ替え」「着せかえ」を機能名に使わない。部位の表示名は「ぼうし」「くびもと」「かばん」、背景のカテゴリは「ひろば」。アイテムの固有名は保つ。 |
| 操作の練習           | チュートリアル         | 参照用の「あそびかた」と区別する。その場の短い説明は「あそびかたガイド」。                                                                       |
| 日ごとの継続         | 連続記録               | 「ストリーク」「自炊の連続記録」を表示名に使わない。日数は「○日連続」、報酬は「継続ボーナス」。日数を示す場合は「○日連続ボーナス」。             |
| 記録を促す機能       | ごはんのお知らせ       | 「ごはんのリマインダー」と混在させない。設定の選択肢は「ひかえめ」「しっかり」。                                                                 |
| 成長に使う値         | 経験値（XP）           | 最初の説明では対応を示す。本文は「経験値」、数値・ゲージは「XP」。次の段階への残量は「次の成長まで」。                                           |
| 料理未選択時の名前   | 今日のごはん           | 選択欄、入力例、保存時の既定名を揃え、「いつものごはん」と混在させない。                                                                         |
| おやすみ用のアイテム | おやすみチケット       | 「おやすみ券」「休み券」と混在させない。                                                                                                         |
| 検索の絞り込み       | 種類・調理時間・難しさ | 「分類」「難易度」を操作ラベルに使わない。条件の初期化は「条件をリセット」。                                                                     |
| 一覧のページ送り     | 前のページ・次のページ | 「前へ」「次へ」と混在させない。食事などの進行操作は「つづける」。                                                                               |

世界設定の種名・個体名・地名は[用語集](world/glossary.md)に従う。たとえば「ホエリ」は種名、「こむぎ」は個体名であり、同義語として置き換えない。外部作品の名称・引用、旧仕様を説明する名称、コードの識別子や保存IDは、それぞれの文脈を保つ。

## 話者と説明の範囲

- **なかま**：食べる、喜ぶ、おなかを空かせるなどの反応を姿と動きで伝える。会話の吹き出しは常設しない。動きがなくても状態ラベルや読み上げで意味を確認できるようにする。
- **システム**：操作名、現在の状態、起きた出来事、必要な条件を簡潔に示す。誰かの発言に見える呼びかけや心情の代弁を混ぜない。
- **手順説明**：初回と、ユーザーが開いた「あそびかた」に置く。通常の食事では同じ説明を繰り返さない。エラーからの復帰方法や操作に必要な条件は、その場で表示する。

案内人物は導入しない。将来導入する場合は、その人物の役割と、その場で発言する目的を先に定める。発話には名前や姿を伴わせ、既存の説明を集約する。人物を置くことで説明量が増えないことを条件とする。

## 一画面の文字予算

1. **画面の見出しは1個**。画面の目的か結果を示す。上見出し・見出し・副題で同じ内容を言い直さない。ずかんの詳細や設定内の区分名は、情報を探すために必要なものだけ置く。
2. **主操作は1個**。実行する行動が分かるラベルにする。戻る・閉じる・写真変更などは補助操作として扱う。
3. **説明は判断に必要なときだけ**。基本は1文。削除しても操作や結果の理解が変わらない文は置かない。複数の条件や手順は詳細・あそびかたへ移す。

ひろばではなかま、状態、給餌操作を中心にする。写真選択では写真と選択操作、食後ではなかまの反応と今回の結果を中心にする。画面に余白があってもキャプションで埋めない。

## 文言の責務

| 種類                 | 伝えること                                         | 例                                                     |
| -------------------- | -------------------------------------------------- | ------------------------------------------------------ |
| 機能・操作ラベル     | 押した後に行うこと、開くもの                       | 写真を選ぶ／ごはんをあげる／レシピを見る               |
| 状態                 | 今どうなっているか                                 | 空腹／満腹／今日のごはん 未記録                        |
| 結果                 | 今回起きた変化と獲得量                             | こむぎが成長／カード獲得／コイン +30                   |
| エラー               | 起きた問題と次にできること                         | 写真を読み込めませんでした。別の写真を選んでください。 |
| ずかんの説明・設定文 | なかまの特徴、料理の材料・手順など、開いて読む内容 | なかまの好みや習性を三人称で記述する                   |
| アプリ設定の説明     | 変更する内容と実際の効果                           | 選択肢だけで意味が伝わらない設定に補足する             |

ずかんの設定文は一覧や食事画面へ繰り返し表示しない。エラーや制約は判明している事実を書く。なかまの気持ちを理由にせず、次の操作を示す。

なかまの説明では、世界設定を矛盾がないか確かめるための背景として使う。暮らし、食べ方、癖、成長してできることを平易な言葉で書く。固有名詞は世界を身近に感じられるところへ少し添え、「麦畑の広がるアシロ島」のように何を指すかも文の中で伝える。設定集の要約や用語の羅列にせず、設定を知らなくても楽しめる文章にする。共通の説明と各成長段階の説明を分け、各段階は姿の変化に行動や能力を結びつけた短い数文にする。

## 句読点と文体

- 見出し、ボタン、タブ、短い状態・結果ラベルには句点を付けない。
- 装飾的な読点や余韻を作る省略記号を使わない。「きみの、ごはん。」「いっしょに…」のような区切りで雰囲気を足さない。
- 説明本文は自然な文として書き、意味を明確にする読点と句点を残す。句読点を一律に削除しない。
- 操作は具体的な動詞、結果は具体的な変化で示す。感嘆符、擬音、励ましをすべての画面に付けない。
- 同じ機能には同じ名称を使う。絵やラベルで分かる内容を、別の言葉の補足で繰り返さない。

## 改稿例

| 改稿前                           | 改稿後                                       | 意図                                         |
| -------------------------------- | -------------------------------------------- | -------------------------------------------- |
| 今日の一皿、見せて。             | 料理の写真                                   | 呼びかけを画面の目的に置き換える             |
| いつものごはんで、だいじょうぶ。 | 削除                                         | 写真選択に必要な情報が増えない               |
| ごはん、できたよ。               | ごはんをあげる                               | プレイヤーの発言を代筆せず操作段階を示す     |
| ごはんを分けると、なかまに。     | お客さんにごはんをあげるとなかまになります。 | ルールを自然な文にし、初回・あそびかたに置く |

## 参考にした公式資料

以下は公開資料の観察と、本作の設計判断を分けて扱う。公式の文章規則を採用したものではない。

- [Pokémon Sleep公式キャンペーン](https://www.pokemonsleep.net/cp2024/)：ネロリ博士の名前と姿を伴う研究協力の依頼と、開催条件・注意事項が別にある。本作では話者と目的を明確にする原則を採用し、案内人物は追加しない。
- [公式ヘルプ：睡眠データ](https://app-psl.pokemon-support.com/hc/ja/articles/29323063556761-%E7%9D%A1%E7%9C%A0%E3%83%87%E3%83%BC%E3%82%BF%E3%81%AF%E3%81%A9%E3%81%AE%E6%97%A5%E3%81%A8%E3%81%97%E3%81%A6%E3%82%AB%E3%82%A6%E3%83%B3%E3%83%88%E3%81%95%E3%82%8C%E3%81%BE%E3%81%99%E3%81%8B)：操作名は「ねむる」「計測を終了する」。本作でも行動を表すラベルを用いる。
- [公式ヘルプ：フレンド追加](https://app-psl.pokemon-support.com/hc/ja/articles/21535589371417-%E3%83%95%E3%83%AC%E3%83%B3%E3%83%89%E8%BF%BD%E5%8A%A0%E3%81%8C%E3%81%A7%E3%81%8D%E3%81%BE%E3%81%9B%E3%82%93)：チュートリアル前後で機能の入口が異なる。初回と通常画面を分ける参考とする。手順説明を初回・あそびかたに限定することは本作の判断であり、同作の説明頻度を示すものではない。

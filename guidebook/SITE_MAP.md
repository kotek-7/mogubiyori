# もぐ日和 世界の案内帖：章とページ

プロダクトと独立した静的サイト。先に以下の章・詳細ページ・回遊を用意し、それぞれに図版と読み物を入れる。

| 章             | 一覧ページ   | 個別ページ                                       |
| -------------- | ------------ | ------------------------------------------------ |
| 表紙           | `/`          | 今日の一篇と各章への入口                         |
| はじめに       | `/welcome/`  | ナロの成り立ち、人ともぐの距離、案内の手紙       |
| 島をめぐる     | `/islands/`  | 六島それぞれの地誌、交易と航路                   |
| 暮らしの寄り道 | `/village/`  | 村の散歩と、六島の新しい店・場所・風習への寄り道 |
| もぐを知る     | `/mogs/`     | 主な六種の個別生態誌、六島別の36種短録           |
| 食卓と暮らし   | `/table/`    | 六島の郷土料理のページ、口合わせ、かまどの一日   |
| 村の人々       | `/people/`   | ミナ、ガロ、サヨ、オル、トキの個別ページ         |
| 島のものがたり | `/stories/`  | 新作短編八篇をそれぞれ独立した読み物に           |
| ことばのしおり | `/glossary/` | 地名・人名・生態・暮らしの用語集                 |
| 総目次         | `/contents/` | 章ごとの全ページへの直接リンク                   |

全ページに現在の章、パンくず、関連ページ、総目次への入口を置く。詳細ページは章内の前後の記事にも進める。各章の一覧は単なるリンク集ではなく、地図、図版、日課、人物の紹介など、単独でも読める見開きとして扱う。

## 設定の扱い

`../docs/world.md` と `../docs/world/` を地理・生態・人物のバックボーンとし、新作短編、寄り道先、風習をここから創作する。公開本文に実装・編集手順を混ぜない。原稿の由来と制作上の注意は README に残す。

もぐは人間の会話をしない。ミナは十歳で、大人の仕事をすべて担わない。種の名と個体名を区別し、食事は報酬としての労働の対価にしない。成長や島の環境に魔法を導入しない。

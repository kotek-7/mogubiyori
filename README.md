# もぐ日和

**きみのごはんで、こむぎが育つ。**

自分で作った料理の写真を、小さな相棒「こむぎ」に届ける育成ゲームです。ごはんをあげると、おなかが満ちて、少しずつ成長します。

**おへや → 料理の写真 → ごはんをあげる → 成長とストリーク → また明日。**

## 起動

Node.js 22.12以降を用意します。

```sh
npm ci
npm run dev
```

pnpmを使う場合は `pnpm install`、`pnpm run dev` でも起動できます。

スマートフォンでは、PCと同じネットワークに接続して `npm run dev -- --host 0.0.0.0`（pnpmの場合は `pnpm run dev --host 0.0.0.0`）を実行し、表示された **Network URL** を開きます。端末間通信が制限されたゲストWi-Fiでは接続できません。

```sh
npm run build
npm run preview
```

`dist/` を静的配信できます。PCとスマートフォンに対応し、キャラクター、料理イラスト、フォントは同梱しています。

## 遊び方

- **おへや**：おなかをすかせたこむぎに、料理の写真でごはんをあげます。料理名は任意です。
- **成長**：その日最初のごはんで45 XPと30コイン。連続で作るとストリークが伸び、7日で「ふたばのかんむり」を獲得します。
- **思い出**：一緒に食べた料理を写真で振り返ります。
- **おみせ**：コインやジェムで帽子・おへやを購入して着せ替えます。

写真がないときはサンプルの一皿でも体験できます。ジェム追加は試用操作であり、実際の支払いは発生しません。

## 体験の設定

設定から日付を進め、翌日の空腹や、作れなかった日の後の再開を試せます。まっさらな状態へのリセット、リマインドの口調の切り替えもできます。

おやすみチケットはストリークを守りますが、こむぎのおなかは満たしません。休んでもキャラクターが死んだり、獲得済みの経験値が減ったりすることはありません。

## 保存と実装範囲

記録・写真・育成・購入状態は、このブラウザの `localStorage`（`mogubiyori-v1`）に保存します。再読み込み後も残りますが、端末間では共有されません。サイトデータを消すと記録も消えます。

日付は実際の日本時間に追従し、設定で進めた日数を加算します。写真は端末内で縮小して保存します。画像認識による料理や自炊の判定、認証、クラウド保存、プッシュ通知、実決済は未実装です。

```sh
npm test

npm run build
npm run format:check

npx playwright install chromium
npm run test:e2e
```

E2Eはポート5173を使用します。起動済みのサーバーがある場合はそのサーバーを使用します。

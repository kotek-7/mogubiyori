# ひとさじ

**自炊に、ちいさな火を。**

写真1枚で今日の「つくれた」を残し、明日の自炊につなげる習慣アプリです。

**今日の一皿を残す → 写真を選ぶ → 記録する → 継続達成 → また明日。**

## 起動

Node.js 22.12以降を用意します。

```sh
npm ci
npm run dev
```

表示されたローカルURLを開きます。スマートフォンから同じネットワークで試す場合は、`npm run dev -- --host 0.0.0.0` を実行し、表示された Network URL を開きます。端末ごとに記録は分かれます。

```sh
npm run build
npm run preview
```

`dist/` は静的配信できます。画面の移動はハッシュURLを使うため、ルーティング用のサーバーは不要です。公開先へのデプロイは行っていません。

## 試せること

- **今日**：連続日数、今週の記録、今日の一皿を残すボタン。記録後は今日の完了を表示します。
- **写真で記録**：写真だけで保存できます。料理名・ジャンル・メモ・公開範囲は任意。写真なしのサンプル体験もできます。
- **継続と休み**：記録直後に継続日数を祝福。おやすみチケットで休む日も支えます。
- **記録・食卓**：アルバムの振り返りや、仲間の料理は下のタブから開けます。
- **献立ノート**：「献立に迷ったら」から、時間と食材に合う一品を探し、手順を確認できます。

画面はPCとスマートフォンに対応しています。料理イラストはSVG、フォントは同梱され、起動後の表示に外部APIキーや外部画像配信は必要ありません。

## アイデアの実験室

右上の設定から開けます。直接開く場合は `/#lab` にアクセスします。

| 比較する項目         | 選択肢                              |
| -------------------- | ----------------------------------- |
| 献立の決め方         | 今日の1択 / 次の3食                 |
| 継続のルール         | 毎日 + おやすみ / 週3日の目標       |
| 同じ料理が続いたとき | 新しい挑戦への加点 / 繰り返しを減点 |
| 食卓の入口           | 記録してから / いつでも見る         |
| おたよりの口調       | やさしい提案 / 継続をリマインド     |

日付を翌日に進め、記録がない日や休んだ翌日の状態を再現できます。初期状態は6日継続。「はじめての自炊」では空のアルバムから試せます。状態の初期化前には確認が表示されます。

比較設定・操作履歴・検討メモをJSONに書き出せます。料理の写真データは書き出しに含めません。

## データと実装範囲

このプレビューはブラウザ内で完結します。記録・写真・設定は `localStorage` の `hitosaji-demo-v1` に保存され、再読み込み後も残ります。ブラウザのサイトデータを消すと記録は失われます。

- 献立は時間・食材・履歴を使う決定的なルールで提案します。外部の生成AIは呼び出しません。
- 写真は読み込み・縮小・保存されます。画像認識は未接続です。料理名とジャンルは任意入力で、省略すると「今日の一皿」「未分類」で保存します。
- 仲間の投稿はサンプル。いいね・フォロー・匿名や友達向けの公開状態は端末内のプレビューです。
- 認証、クラウド保存、端末間同期、友達への配信、プッシュ通知、課金は未実装です。
- 日付は初回の日本時間で固定し、実験室から進めます。実際の深夜0時に自動更新する運用ではありません。
- 保存容量が不足すると画面に通知し、未保存のまま操作中の状態を維持します。多数の写真を扱う実サービスでは画像用ストレージへの移行が必要です。

## 検証

```sh
npm test                 # 継続、休み、加点、週の境界、保存データの検証
npm run lint
npm run build
npm run format:check

npx playwright install chromium
npm run test:e2e          # 記録・写真・公開範囲・仕様比較・スマートフォンの操作
```

E2Eはポート5173でアプリを起動します。ローカルで既に起動している場合はそのサーバーを使用します。

## 構成

```text
src/
  App.tsx           画面遷移、共有状態、ダイアログ
  pages.tsx         ホーム、献立、アルバム、食卓
  dialogs.tsx       調理、記録、休み、実験室
  domain.ts         レシピと状態遷移、提案、継続・報酬のルール
  storage.ts        保存データの検証、画像縮小
  Illustrations.tsx キャラクターと料理のSVG
  components.tsx    共通のダイアログとカード
  index.css         テーマとレスポンシブレイアウト
```

React・TypeScript・Viteで構成しています。[Viteの起動要件](https://vite.dev/guide/)に対応するNode.jsを使用してください。

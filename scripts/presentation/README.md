# 発表用メディアの書き出し

このディレクトリは、ゲームを変更せずに発表用の画面・動画・画像素材を作るためのスクリプトを管理します。

出力先はリポジトリ直下の `artifacts/presentation-kit/` です。画面と動画はローカルモードの専用ブラウザーで撮影し、発表用の保存状態を用意します。普段のブラウザーの保存内容やクラウドのデータは使用しません。

操作動画・大量の PNG・ZIP は Git の対象から外しています。再現用スクリプトと画像生成プロンプトを Git に残し、完成したキットは `main` の作業ディレクトリにもコピーします。

詳しい実行順序と素材の使い方は `docs/presentation/README.md` を参照してください。
